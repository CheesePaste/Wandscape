# 魔法阵设计原则（从 UsefulMagic 提炼）

本文从第三方模组 **UsefulMagic**（GPL-3.0，参考样例见 `usefulmagic-examples/`）的魔法阵实现中提炼出一套可迁移到 Wandscape `MagicCircleSpec` 的设计原则。目的是让后续设计魔法阵时有章可循，避免"堆元素但不好看"。

> 适用对象：`data/wandscape/magic_circles/*.json` 的编写者 / [Web 编辑器](https://github.com/CheesePaste/magic-circle-editor)（独立项目）使用者。schema 见 [magic-circles.md](magic-circles.md)。

> **配套示例**：按本原则设计的大型六芒星召唤阵 → [example-specs/arcane_hexagram.json](example-specs/arcane_hexagram.json)（半径 8.0，8 层，可在编辑器导入查看）。
>
> **配套示例**：self_teleport 传送阵三个候选变体（单层 / 紫色 / 从内到外级联展开）→ [`../../magiccircles/`](../../magiccircles/)（本地草稿，gitignore 不提交；确认选型后才进 src，见文末「传送阵设计模式」）。

## 核心心法

**一座好看的魔法阵 = 5~8 个"简单层"的叠加，每层只做一件简单的事。**

UsefulMagic 的所有阵法（Small/Mid/LargeFormationStyle）都是 `getCurrentFrames()` 返回若干个独立层（`StyleData`），每层独立半径、转速、旋转方向、缩放动画。复杂度来自**层数**和**层间关系**，不来自单层内部。

设计顺序建议（从贵到便宜，贵的先定）：

1. **分层** — 先想这座阵有哪几层（外环 / 内环 / 几何骨架 / 符文 / 中间点缀）。
2. **定半径** — 各层半径有主次（如 4.0 / 2.6 / 3.4），避免全部等距（会显得平）。
3. **按层定转速** — 先分层，每层一个 `rotate_speed`，同层同速、相邻层异向（P13）。
4. **定入场/出场动画** — scale 从 0 缓动涨起、尾段缩小淡出。
5. **选粒子与色系** — 1 种主力粒子 + 同一色系，≤2 色。

## 19 条原则

### P1. 相邻**层级**异向旋转，是最便宜的"活气"
UsefulMagic 到处是 `rotateAsAxis(PI/128)` 与 `rotateAsAxis(-PI/128)` 交替。异向旋转制造视差，读者一眼觉得"它是活的"。

- Wandscape 对应：**相邻层级** `rotate_speed` 取相反符号（如 `23` / `-17`）。
- 让最外层快转、核心符文层慢转，层级感更强。
- **同层级内禁止异向**：同层元素必须同速（见 P13）。

### P2. 虚实交替出节奏 — 实环 + 亮点环 + 几何形
每个法阵都应有三种"质感"的层交替出现：
- **实环**（`continuous`）— 拖尾密度，做基底。（旋转阵**禁**用 continuous 拖尾，用高密度 beads 代替，见 P17）
- **亮点环**（`beads`）— 均布有序亮点，做骨架（UsefulMagic 的 `addDottedCircle`）。
- **几何形**（正多边形/星形）— 做"棱角感"，纯圆会糊。

### P3. 相位错开 = 双环不打架
两圈同半径亮点环，第二圈用 `rotation_offset_deg` 偏移半周期，亮点就交错排列（UsefulMagic：两个 `addDottedCircle` 相差 `PI/16`）。

- 适用：双层菱形 / 双层三角 / 双层亮点环。

### P4. 正多边形环给法阵"骨架感"
UsefulMagic 几乎每座阵都有 `addPolygonInCircle`（3/4/5/6/12 边）。三角（能量）、四角（稳定）、六角（传送/六芒）、八角（星芒）是经典视觉语言。

- **契约已支持**：`polygon`（`sides`）与 `star`（`points` + `inner_ratio`，`star` 即六芒星/星芒），见 [magic-circles.md](magic-circles.md)。
- 双层多边形错 45° 叠加 → 八角星；双 `star` 反向旋转 → 动态六芒星。

### P5. 顶点挂载符文，别手写每个符文
UsefulMagic 用 `addPolygonInCircleVertices(12, r)` 取顶点，再在**每个顶点**上 `addBuilder(vertex, 子环/子形)`。glyph 环形布置本质上就是这个。

- Wandscape `glyph.count` 已是均布顶点。**缺口**：若要做"顶点处小环/星芒"，需要 `on_vertices` 挂载能力或显式相位列表（`phases: [...]` 指定符文落点），否则只能均布。

### P6. 入场用缓动放大，不是线性
UsefulMagic 用贝塞尔缩放（`CompositionBezierScaleHelper`：10 tick，0.01→1.0），先快后慢；入场附弹性旋转（`SkillRangeDisplay`：`outElastic` 180°→0° 入位）。

- Wandscape 对应：`scale` 关键帧用缓动曲线（如 `[[0,0],[0.5,1.1],[1,1]]`），别 `[[0,0],[1,1]]` 线性涨。
- **已支持**：`anim.easing` 可选 `linear` / `smoothstep`（默认 linear）。`smoothstep` 即先慢后快再慢的平滑过渡。UsefulMagic 的 `outBack`（过冲）/`outElastic`（弹性）尚未收录。

### P7. 出场 = 逐层错开缩小消散
UsefulMagic `reverseScaleOrRemove` 逐层 `doScaleReversed()` 缩小，配合 DISABLE 状态。层多时不要同帧一起消失——错开 `start` 让消散也有层次。

- Wandscape 对应：`alpha` 尾段 → 0、`scale` 尾段 → 0，各元素 `start` 错开。

### P8. 状态驱动转速 — 待机/工作两种节奏
UsefulMagic 有 `FormationStatus.IDLE/WORKING`：IDLE 慢转（PI/256），WORKING 快转（PI/128）。切换转速是"它被激活了"最便宜的信号。

- **已有半套**：`interval_ticks` 是脉冲（on/off 闪烁），可做"呼吸"；但**没有真正的循环播放模式**（单次播放到 t=1 即止）。若做领域/结界等持续阵，需 `repeat`/`loop` 能力或 `phase`（循环待机 + 施法加速）。传送/仪式一次性施放无需此能力。

### P9. 粒子风格克制 — 一种主力 + 同色系
UsefulMagic 几乎所有阵法粒子都用 `ControlableEndRodEffect`（end rod），靠染色 + `size` 区分。极端统一反而高级。

- Wandscape：一个法阵尽量 1 种主力粒子（同色系），跨色系 ≤2 色。色系决定法阵"属性感"：火=橙红、雷=青蓝、传送=紫、奥术=蓝青。
- **注意 MC 端支持子集**：编辑器有 60 种风格，MC 端只映射 13 个原版风格 + glow/ember 两个自定义染色点，其余回退染色点（见 magic-circles.md"粒子风格"节）——设计时只用子集内的风格。

### P10. 半径由"阵规模"定，元素写相对值
UsefulMagic 把结构（`FormationScale`：小/中/大水晶布局）与表现（particle style 消费半径）分离。

- **Wandscape 缺口**：radius 直接写在元素上。若未来做多级阵，顶层给 `scale` 乘子，元素写相对半径即可复用同一份 spec。

### P11. 表现力优先级：旋转 > 缩放 > 透明度 > 颜色
从样例观察，做"好看"的成本排序：异向旋转（最便宜）→ 缩放动画（入场/消散）→ alpha 开合 → 颜色（最后动）。设计时先把前两项做对，alpha 只做开合，颜色保持统一。

### P12. 整张贴图路线是"高精度静态"补充
UsefulMagic 有三张完整法阵 PNG（`magic_*.png`）直接 billboard 渲染。优点是精细便宜，缺点是无法参数化动画。Wandscape 走粒子路线（JSON 可调、可动画）是对的——贴图路线只作为特殊静态场景的补充，不入主契约。

### P13. 转速看"重叠/相切"，不看半径 —— 重叠必须同速，相切必须异向
两个图形的角速度该不该相同，取决于它们的**位置关系**，而不是半径或"层级"：

- **重叠**（粒子占据同一区域/交错）：**必须同角速度**，否则互相打架、糊。
- **相切**（只接触、不重叠）：**必须异向/不同速**——相切还同速会像"锁死"一样**呆板**。异向是制造视差的主要手段。
- **同视觉整体**（与宿主构成一体，如星星凹陷缺口里的符文）：即使错开不重叠，也应与宿主**同角速度**——它是"宿主的一部分"，跟着宿主转。
- 判断法：先算粒子落点是否共点/共区（决定重叠与否），再据此定转速。
- 反例（会翻车）：内接六边形与星星相切却同速 → 呆板；符文与星星内凹粒子重叠却异向 → 打架。

### P14. 符文/子元素放"凹陷缺口"里，绝不与宿主粒子重叠
首要原则：**绝不重叠**——子元素落点与宿主形状的任何粒子坐标重合，粒子就叠成一坨，很难看。

- **星形符文**：**别放内凹顶点**（半径 = 外半径 × `inner_ratio` 处与星形自己的内凹粒子**完全重合**）。放**凹陷缺口里**：半径取宿主内半径与外半径之间、角度对齐缺口，错开宿主粒子。
  - 例：六芒星 R=5.5、inner 0.5 → 内凹 2.75、外尖 5.5 → 符文 **r=4.0、角度 30°+60k**（正好在 6 个 V 形缺口里，距星形粒子都有距离，不叠）。
- **多边形符文**：放角间/边中点，同样半径错开（× cos(π/sides)）。
- **放前先算坐标**：子元素落点与宿主每个粒子的距离必须 > 两者尺寸和，否则重叠。宿主让位 / 子元素错位，二选一。
- 视觉密度均匀（不空一块密一块）是结果：符文在缺口里把"空心"填上，顶点是锋芒不堆叠。

### P15. 相邻层留足净间距 —— 不密不空，边界差才是关键
"不重叠"只是下限，**没重叠但挨太近也一样密**。同心层之间要留呼吸间距：

- 判据看**净间距**（相邻层边界之差，不是半径差）：内层外缘 vs 外层内缘。
  - 例：六边形内接 r2.75，边中点距心 = 2.75×cos(30°) ≈ 2.38；内亮点环 r2.0 → 净间距 0.38 太挤，移到 **r1.5** → 净间距 0.88。
- 经验带：同心层净间距 ~**0.8~1.2 格**。太密（<0.5）糊成一团，太疏（>2）显空、脱节。
- 排完半径逐层算**边界差**：多边形/星形等形状要按**边中点距心**（r·cos(π/sides) 或内凹半径）算，不是按外接半径。
- 与 P14 合起来：先保证不重叠，再保证间距平衡——不密不空。

### P16. 级联展开 ≠ 整体放大 —— 从内到外一圈圈出现，每圈定尺寸

"入场变大"有两种观感截然不同的做法：

- **整体放大**（P6）：全阵 `scale` 从 0 涨到 1，读者看到"一个圆从小到大"（光束魔法的观感）。
- **级联展开**：各圈**半径不变**（`scale` 恒 1），靠不同 `start` 从内到外依次淡入，读者看到"一圈圈从中心往外亮起"——每圈亮起时已是最终尺寸。

传送/召唤类法阵用级联展开，更贴合"空间被逐层打通"；传送 = 紫（P9）。实现要点：

- **每圈大小不变**：`anim.scale` 写恒 1（`[[0,1],[1,1]]`）；禁止 `[[0,0],[0.5,1]]` 式放大。
- **从内到外**：`start` 按半径**升序**排——核心最早（0），最外环最晚。
- **淡入/淡出**：`alpha` 头段 `[[0,0],[0.15,1],...]` 缓动淡入、尾段归零；元素 `start` 越大局部窗口越短，其淡入在绝对时间上被压缩——级联呈"越外越快"的加速外扩。
- **单层**：全部同一平面（`axis` 缺省水平 / `y_offset`=0 / `height` 统一），不做竖直门环、不做纵向堆叠。

### P17. 旋转层禁拖尾 —— 转起来的东西一律 beads

- `continuous`（trail_ticks 拖尾粒子）随整体旋转会拖出脏尾、糊成一片，**禁止**用于任何旋转元素（`rotate_speed` ≠ 0）。
- 旋转的层一律 `mode: beads` 均布亮点；要"实环"质感用**高密度 beads**（density ≥ 1.5）+ 同半径错相双环（P3）替代。
- `continuous` 只留给**不旋转**的展开效果（`rotate_speed` = 0）：法阵初现的那圈闪亮/扩散，alpha 快速淡入淡出，做"激活"一瞬，不常驻。

### P18. 独立旋转符文放大，符文数随半径疏密

- **独立旋转符文层**（该层只有它一种、且**不在**多边形/星形凹口内的）→ 增大彗星拖尾：`scale` 提到 **0.4~0.5**（默认 0.3 太小、单薄），可配合 `trail_ticks` ≈ 12 加长彗星尾。
- 一圈旋转符文的个数随半径定：**R 大一圈 8~12 个，R 小只有 2~3 个** —— 内到外符文环疏密有层次。
- 例外：嵌在多边形凹口的装饰符文（P14）保持小号、数量随宿主点数，不放大。

### P19. 整体粒子密度宁密勿疏 —— 参考示例密度

- 粒子密度参考 `example-specs/arcane_hexagram.json`：**beads 环 `density` ≈ 1.5**（亮点数 = density × 弧长）、**几何/星形 ≈ 1.8**、**continuous ≈ 1.2**。
- 宁可偏密不要偏疏——疏了圆环显空、拖不出"阵"的密度感；示例观感好主要靠密度够。施法时同屏数百粒子无压力（见 magic-circles.md「粒子模型」节）。

## 传送阵设计模式（示例：从内到外级联）

self_teleport 的三个候选变体为**本地草稿**，只放根目录 [`../../magiccircles/`](../../magiccircles/)（gitignore 不提交），**未进 src**：

| 文件 | 结构 | 半径 | 时长 | 色系 |
|------|------|------|------|------|
| `magiccircles/self_teleport_a.json` | 六芒星 + 双环 + 6 凹口符文 + 核心 | 3.2 | 140t | 亮紫 `#8b5cf6`/`#c4b5fd` |
| `magiccircles/self_teleport_b.json` | 三角几何 + 3 符文 + 双环 + 核心 | 2.8 | 120t | 紫 `#a855f7`/`#d8b4fe` |
| `magiccircles/self_teleport_c.json` | 六芒星 + 双环 + 外层 12 符文环 + 核心 | 5.2 | 170t | 深靛紫 `#6d28d9`/`#a78bfa` |

共同规则（P16/P17/P18/P19）：单层地面阵、紫色系（每张 ≤3 个同族色阶，粒子只用 `glow` 可染色点）、`start` 内→外升序、每圈 `scale` 恒 1、符文放星形凹口且与宿主同速（P13/P14）、相邻层异向旋转、**旋转层全 beads 无拖尾**、独立符文放大、符文数随 R、粒子密度参考示例。

- **选型流程**：在 [Web 编辑器](https://github.com/CheesePaste/magic-circle-editor) 或游戏内 `/wandscape magic` 预览三个变体 → 挑中并定稿 → **确认后才能**把选中的 spec 放进 `data/wandscape/magic_circles/`（src）正式接线（`circle_id` 引用）。
- **草稿与成品分离**：`magiccircles/` 只存本地候选；进 src 的 spec 才算数。落选变体留在 `magiccircles/` 或删除，不提交。

## 检查清单（写完一个 JSON 后自查）

- [ ] 层数 5~8，每层只做一件事
- [ ] 至少 1 圈亮点环 + 1 个几何/符文层（旋转阵"实环"用高密度 beads 代替，continuous 仅展开用，见 P17）
- [ ] **旋转层一律 beads、无 continuous 拖尾**（P17）
- [ ] **相切元素异向/不同速，重叠元素同速，同视觉整体同速**（P13）
- [ ] **符文在凹陷缺口、且与宿主粒子不重叠**（落点距离 > 尺寸和）（P14）
- [ ] **相邻层净间距 ~0.8~1.2 格，不密不空**（按边中点距心算边界差）（P15）
- [ ] 相邻层转速异向，外层快内层慢
- [ ] 入场 scale 用缓动曲线，出场 alpha/scale 尾段归零
- [ ] 各层 `start` 错开（级联展开）
- [ ] **独立旋转符文 scale 0.4~0.5，符文数随半径疏密（大 R 8~12 / 小 R 2~3）**（P18）
- [ ] **粒子密度参考示例：beads ≥1.5 / 几何 ≥1.8 / continuous ≥1.2**（P19）
- [ ] 粒子 ≤2 种（且都在 MC 端子集内），色系统一
- [ ] 高度（`y_offset`）不全挤在 0

## 编辑器能力现状与后续缺口

**已支持**（编辑器与契约文档已同步）：

| 能力 | 用途 |
|------|------|
| `polygon` / `star` 元素 | 正多边形环 / 星芒（P4 已落地） |
| `anim.easing`（linear/smoothstep） | 关键帧缓动（P6/P10 部分落地） |
| `interval_ticks` | 脉冲 on/off 闪烁（呼吸节奏） |
| 60 种粒子风格（编辑器侧；MC 端支持 13 原版 + 2 自定义子集） | 编辑器**可视化粒子选择器**：贴图网格 + 可染色标记（P9 已落地） |

**仍缺口**（按价值排序）：

| 缺口 | 来源原则 | 说明 |
|------|---------|------|
| glyph 相位列表 / `on_vertices` | P5 | 符文只能均布，无法指定落点或挂载子形（顶点小环/星芒） |
| `repeat`/`loop` 持续运转模式 | P8 | `interval_ticks` 只是脉冲，非持续循环；领域/结界阵需要循环播放 |
| 顶层 `scale` 乘子 | P10 | 一套 spec 多级阵复用（半径相对化） |

这些是**设计能力**的扩展，不是当前必须实现的功能；每新增一个再更新本契约与 Web 编辑器。
