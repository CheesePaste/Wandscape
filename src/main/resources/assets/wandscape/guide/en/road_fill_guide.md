# 🌉 Fill & Destroy Modes

These two modes handle **3D terrain**: Fill mode is a 3D paint bucket — bridging, filling pits, laying foundations; Destroy mode is the eraser — removing wrongly paved blocks and flattening terrain.

## Fill (FILL)

**1. Enter the mode.** Press **V** → the **Roads** icon → select **Fill (FILL)** in the mode bar → double-click to pick a material.

**2. Pull out a 3D area.** Press **C** to switch to the crosshair, **right-click** the bottom start point, **left-click** the elevated opposite corner — a 3D bounding box preview is pulled out.

**3. Submit.** Press **Enter**, and the area is instantly filled.

## Destroy (DESTROY)

**1.** Switch to **Destroy (DESTROY)** in the mode bar.

**2.** **Right-click** a reference block (e.g. a wrongly paved stone brick) to tell the system "use this block as the baseline".

**3.** Frame an area and press **Enter**: blocks above the reference are broken, blocks below are filled up to the reference height — flattening in one click.

## Common Questions

**Filled something wrong and want to delete it?** Switch to **Destroy** mode, right-click a wrongly filled block as the reference, frame the area and press Enter — clean.

**Will Destroy remove buildings?** It only processes blocks of the same type as the reference block within the framed area — just frame the right range.
