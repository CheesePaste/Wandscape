# 🌉 Fill & Destroy Modes

These two modes handle 3D terrain: **Fill (FILL)** is used for bridges, pits, and foundations; **Destroy (DESTROY)** is used to remove wrongly paved blocks and flatten terrain.

## Fill (FILL)

1. Enter the mode: press **V** → the **Roads** icon → select **Fill (FILL)** in the mode bar → double-click to pick a material.
2. Pull out a 3D area: aim at the ground and **hold left-click and drag** — a 3D bounding box preview is pulled from the start to the opposite corner, release to finish.
3. Submit: press **Enter**, and the area is filled with the chosen material.

## Destroy (DESTROY)

1. Switch to **Destroy (DESTROY)** in the mode bar.
2. **Left-click** a reference block (e.g. a wrongly paved stone brick) to set it as the baseline height.
3. **Hold left-click and drag** to frame an area, press **Enter**: blocks above the reference are broken, blocks below are filled up to the reference height, flattening the terrain.

## Common Questions

**Filled something wrong and want to delete it?** Switch to **Destroy** mode, left-click a wrongly filled block as the reference, drag a box, and press Enter to clear it.

**Will Destroy remove buildings?** It only processes blocks of the same type as the reference block within the framed area — just frame the right range.
