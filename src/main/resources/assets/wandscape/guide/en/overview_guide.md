# 🏰 Wandscape Global Control Panel & Overview (Overview Panel Guide)

Welcome to the Wandscape control panel! Press **`V`** to open/close this panel at any time.

---

## 🎮 1. Core View & Hotkeys

| Action / Key | Description |
| :--- | :--- |
| **`V` key** | Open / close the Wandscape global control panel |
| **`G` key** | Switch between **Overview view** ↔ **Ground projection view (Ground Mode)** |
| **`C` key** | Unlock / lock the mouse cursor (unlock to freely click panel UI tabs) |
| **`B` key** | Toggle the red outline showing building occupation boundaries |
| **`H` / `F1` key** | Open the built-in detailed help document for the current mode |
| **Right mouse button** | Drag to rotate the view in overview mode |
| **`WASD` keys** | Pan the free-flight view in overview mode |
| **Mouse wheel** | Zoom the camera in / out in overview mode |

---

## 🏛️ 2. Three Core Panel Sections (Sidebar Tabs)

Switch between these three functions via the sidebar:

1. **🏛️ Build Mode**:
   - Contains all buildable buildings: town hall, warehouse, housing, shops, services, infrastructure, etc.
   - **Click a building card** in the bottom building bar to select it, **double-click** to enter placement; in the world **left-click** to rotate, **right-click** to pin the ghost and open the Construction UI, where you can fine-tune **X/Y/Z coordinates** and **Submit** to build.

2. **🛣️ Road Mode**:
   - **Auto/point road laying**: pick a road preset to connect buildings to the main road.
   - **Spline Editor**: click the Spline button to open the 3D spline Bezier editor for easy curves and overpasses.

3. **📊 Stats Mode**:
   - Live view of the town's tourist flow, economic income, population and anomaly warnings.

---

## 🚩 3. Getting Started Tips

1. **Step one**: build the **Town Hall** to attract wizard NPCs to join and manage the town.
2. **Step two**: build the **Warehouse** to store building materials and production supplies.
3. **Step three**: use the **Road tool** to connect buildings to the town road and attract tourists in to spend!
