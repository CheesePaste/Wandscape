# 🏨 Hotel API Guide

The Hotel provides overnight lodging for tourists visiting the town!

---

## 📖 UI Controls & Fields API Reference

| Control / Label | Type / Range | Default | Details |
| :--- | :--- | :--- | :--- |
| **`Max Occupancy`** (`maxOccupancy`) | Display Int | `10` | Total room capacity of the hotel. Determines the cap on tourists who can stay overnight at once. |
| **`Current Occupancy`** | Display Int | `0` | Number of tourists currently staying overnight. |
| **`Guest List`** (`guestNames`) | ScrollableList | empty | List of tourist names currently resting in rooms. |
