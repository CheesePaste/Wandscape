# 魔法阵 Web 编辑器

这篇写给创作者。普通玩家可以直接跳过——游戏里那些漂亮的法阵，就是这个网页工具画出来的。

魔法阵编辑器（`tools/magic-circle-editor/`）是个独立网页，可视化设计粒子特效，导出 JSON 放进模组的 `magic_circles/` 目录，游戏里就能用。

![魔法阵编辑器示意图](wandscape:textures/gui/guide/magic_editor_diagram.png =200x100)

## 能调什么

- **形状**：圆环 / 正多边形 / 多角星，配**边数**（5 就是五角星）。
- **描边与密度**：`beads` 沿外廓均匀分布粒子，避免星形尖角粒子挤成一团；密度越高越浓密。
- **脉冲**：`pulse_interval` 控制法阵呼吸般的涨缩节奏（20 tick 一秒）。
- **投影轴**：`XZ` 平铺地面（常规法阵），`Y` 竖直悬浮（传送门、护盾）。
- **半径与颜色**：大小，以及粒子从生到灭的颜色渐变（支持透明度）。
- **曲线**：拖贝塞尔曲线，精细控制淡入淡出与缩放。

## 快速流程

选形状 → 调动画（描边、脉冲、平滑）→ 拖曲线 → 点 **Export Spec** 导出 JSON，放进 `magic_circles/`。完事。

## 常见问题

**导出的法阵在游戏里是竖着的？** 把投影轴切成 `XZ` 就是平铺地面的；要竖直悬浮才用 `Y`。
