# 🧙‍♂️ 法师 NPC

法师是小镇的双手：盖房子、采元素、做合成、打怪物，全是他们。小镇能转多快、多稳，就看你有多少法师、把他们养得多强。

## 怎么招

- [酒馆](tavern_guide.md)「招募 NPC」直接雇（首次免费）。
- 收编酒馆里的**法师游客简历**（三条需求条全满留下的，免费）。

## 面板（右键法师打开）

**左侧 · 装备（5 格）**

- **法杖槽**：装更好的法杖提升**法术强度**（施法威力）。三档法杖见[合成台](crafting_guide.md)。
- **护甲槽（4 格）**：头盔 / 胸甲 / 护腿 / 靴子，提升护甲减伤。放心穿——不影响外观，法袍照旧，只算数值。

**右侧 · 属性**

| 属性 | 说明 |
| :--- | :--- |
| **生命** | 脱战一段时间自动回血 |
| **魔力** | 施法消耗，随时间回复 |
| **移动速度** | 赶路和搬运效率 |
| **法术强度** | 施法威力 |
| **工作速度** | 建造 / 合成效率 |
| **施法速度** | 施法引导快慢 |
| **护甲** | 伤害减免 |

**底部 · 背包**：点法杖装备、点护甲穿上，简单。

## 战斗

- 法师会**守卫**殖民地：建筑附近出怪自动施法，挨打会自卫反击。
- 打架时按你的[施法策略](strategy_guide.md)选魔法。
- 头顶**名牌**显示名字和状态，一眼看清谁在干什么。

## 几个提示

- **法杖优先**：法术强度直接决定战力，好法杖给主力法师。
- 战死的法师不会消失——去[祭坛](altar_guide.md)复活，只是会虚弱一阵子。
