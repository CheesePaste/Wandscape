# 法师 NPC

法师执行殖民地的建造、采集、合成与战斗。殖民地运转的规模取决于法师数量与装备强度。

## 招募

- [酒馆](tavern_guide.md)「招募 NPC」直接雇（首次免费）。
- 在酒馆收下**法师游客简历**——三条需求条全满的游客会留下简历，可免费招募。

## 面板（准心对准法师，右键打开）

**左侧 · 装备（5 格）**

- **法杖槽**：装更好的法杖提升**法术强度**（施法威力）。三档法杖见[合成台](crafting_guide.md)。
- **护甲槽（4 格）**：头盔 / 胸甲 / 护腿 / 靴子，提升护甲减伤。护甲只影响数值，不改变法袍外观。

**右侧 · 属性**

| 属性 | 说明 |
| :--- | :--- |
| **生命** | 脱战一段时间自动回血 |
| **魔力** | 施法消耗，随时间回复 |
| **移动速度** | 赶路和搬运效率 |
| **法术强度** | 施法威力 |
| **工作速度** | 建造 / 合成效率 |
| **施法速度** | 施法引导快慢 |
| **护甲** | 伤害减免 |

**底部 · 背包**：点法杖装备、点护甲穿上。

## 战斗

- 法师会**守卫**殖民地：建筑附近出现怪物会自动施法，挨打会自卫反击。
- 打架时按你的[施法策略](strategy_guide.md)选魔法。
- 头顶**名牌**显示名字和状态，可看到每个法师当前在做什么。

## 行为设置（面板底部）

- **和平 / 取消和平**：开启后该法师**不攻击任何生物**——不再守卫建筑、不再自卫反击，已出手的光束立即停手（复活、建造、合成照常）。适合把法师调去纯生产。
- **跟随 / 取消跟随**：开启后法师会跟着你——你离它超过 **5 格**时它会走向你，靠近到 3 格内停下。**跟随期间法师不再接取、也会停下手头的殖民地任务（建造/采集/守卫等）**，自防御等个人行为不受影响。适合带法师出门或搬家。
- **解雇**：永久移除该法师——装备（护甲 / 自定义法杖 / 已装备卷轴）掉落在原地，法师小屋恢复空置。**解雇不可被复活魔法找回**，操作会弹确认框。

## 提示

- **法杖优先**：法术强度直接决定战力，好法杖给主力法师。
- 战死的法师不会消失——去[祭坛](altar_guide.md)复活，复活后短暂虚弱。
