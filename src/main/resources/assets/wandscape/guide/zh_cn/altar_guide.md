# 🏛️ 祭坛

施放**仪式魔法**的设施。目前可施放的仪式魔法为**复活**。仪式魔法不会由法师在战斗中自动施放，需在祭坛下达。

## 施放仪式魔法

1. 按 **V** 打开面板，**准心对准祭坛，右键**打开祭坛面板。
2. 列表列出可施放的魔法，每行标注**名称 / 蓝耗 / 冷却 / 引导时长**。
3. **单击**选中一行（仅高亮，不施放）。
4. 点右下角 **Submit**——殖民地派遣一名魔力足够的法师走到祭坛旁施放，法阵在祭坛中心展开。
5. 施放结束前显示「施法中」；每个祭坛的每种魔法**独立冷却**，互不干扰。

## 复活

| 项目 | 说明 |
|---|---|
| 目标 | 本殖民地**最近死去的一名法师**，不限死亡地点 |
| 效果 | 法师在**祭坛中心**重生，名字、外观、属性、背包原样恢复 |
| 代价 | 复活状态为**虚弱**——1 血 0 蓝，靠脱战回血与魔力回复逐步恢复 |
| 前提 | 需存在死亡记录（死亡记录永久留存，复活成功后才删除） |

## 提示

- 施放消耗的是**执行任务的法师**的魔力；殖民地无魔力足够的法师时无法提交。
- **发布即锁定**：提交后锁定至施放结束，避免重复施放。
- 祭坛魔法不在法师的自动施法策略中，需手动到祭坛下达。
