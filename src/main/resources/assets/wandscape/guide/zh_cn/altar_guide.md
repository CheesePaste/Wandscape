# 🏛️ 祭坛

法师会战死。祭坛就是你的后悔药——目前它只会一种仪式魔法：**复活**。这种魔法法师自己在战斗里永远不会用，得由你来祭坛下令。

## 施放仪式魔法

1. 按 **V** 打开面板，**右键祭坛**打开祭坛面板。
2. 列表列出可施放的魔法，每行标着**名称 / 蓝耗 / 冷却 / 引导时长**。
3. **单击**选中一行（只是高亮，不会放）。
4. 点右下角 **Submit**——殖民地会派一名魔力够的法师走到祭坛旁施放，法阵在祭坛中心展开。
5. 施放结束前显示「施法中」；每个祭坛每种魔法**独立冷却**，互不干扰。

## 复活是怎么回事

- **目标**：本殖民地**最近死去的一名法师**，不限死在哪。
- **效果**：法师在**祭坛中心**重生，名字、外观、属性、背包原样回来。
- **代价**：复活出来是**虚弱的**——1 血 0 蓝，靠脱战回血和魔力回复慢慢养。
- **前提**：得先有死亡记录（法师的死亡记录永久留存，复活成功才删）。

## 几个提示

- 施法扣的是**执行任务的法师**的魔力；殖民地没有魔力够的法师时提交不了。
- **发布即锁定**：提交后锁到施放结束，防止你手滑重复刷。
- 祭坛魔法不在法师的自动施法策略里——想复活，就来祭坛，别指望他们自己起来。
