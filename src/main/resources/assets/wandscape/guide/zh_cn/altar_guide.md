# 🏛️ 祭坛（Altar）使用指南

祭坛是魔法小镇的核心仪式建筑：玩家在此提交命令，殖民地会自动指派一名法师走到祭坛中心，代为施放**祭坛专属魔法**（如复活）。

---

## 🎯 如何使用

1. 靠近祭坛并**右键**打开祭坛面板。
2. 列表列出祭坛可施放的**祭坛专属魔法**（每行显示：名称 / 蓝耗·冷却·时长）。
3. **单击**选中一行（高亮）。
4. 点击右下角 **Submit** 提交——殖民地会指派一名魔力足够的法师走到祭坛中心施放。
5. 施放结束前该魔法标记为「施法中」，且该祭坛该魔法进入独立冷却。

> 💡 祭坛专属魔法（如复活）只能通过祭坛施放，法师自动战斗不会使用它们。

---

## 📖 UI 控件说明

| 控件 / 标签 | 类型 | 详细作用机制 |
| :--- | :--- | :--- |
| **魔法列表** | 列表 | 列出所有祭坛可施放的魔法。每行显示名称、蓝耗（需消耗的魔力值）、CD（冷却时长）、时长（引导施法时长）。 |
| **魔法行状态** | 文本 | `可施放` = 就绪；`冷却中 Ns` = 该祭坛该魔法冷却未结束；`施法中` = 已有法师正在施放；`已安排` = 本次会话已提交。 |
| **Submit** | 按钮 | 为选中魔法发布祭坛施法任务。仅当有选中项且未锁定、未冷却、未提交时可用。 |

---

## ⚙️ 机制细节

- **消耗魔力**：施放消耗殖民地法师的魔力值；殖民地内没有魔力足够（≥ 蓝耗）的法师时无法提交。
- **施法流程**：法师走到祭坛中心，引导施法 `时长` tick 后完成。
- **独立冷却**：冷却按祭坛（建筑）独立存储，不同祭坛互不共享；施放完成后开始计时。
- **发布即锁定**：提交后即锁定，直到施放结束，防止重复发布。
- **复活魔法**：需要该殖民地存在可复活的死亡记录（NPC 死亡记录永久留存，复活成功后删除）。
