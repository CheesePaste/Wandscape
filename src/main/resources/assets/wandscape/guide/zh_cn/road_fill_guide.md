# 填充与清理模式

这两个模式处理立体地形：**填充（FILL）**用于架桥、填坑、搭基座；**清理（DESTROY）**用于拆掉错铺的方块、整平地形。

## 填充（FILL）

1. 进模式：按 **V** → **道路**图标 → 模式栏选**填充（FILL）** → 双击挑材质。
2. 拉立体区域：鼠标瞄准地面，**按住左键拖框**拉出立体包围盒预览（从起点拖到对角），松开完成。
3. 提交：按 **Enter**，范围内填满选定材质。

## 清理（DESTROY）

1. 模式栏切**清理（DESTROY）**。
2. **左键**点击一个参照方块（例如错铺的石砖），将其设为基准高度。
3. **按住左键拖框**选范围按 **Enter**：高于参照的方块被拆掉，低于参照的方块被填到参照高度，实现整平。

## 常见问题

**填错了想删？** 切**清理**模式，左键点错填的方块当参照，拖框回车，即可清除。

**清理会不会拆掉建筑？** 它只处理框选范围内与参照方块同类的方块，选准范围即可。
