# 🧳 游客

游客是小镇的摇钱树，也是最难伺候的客人：他们清晨沿路进镇，逛店、消费、过夜，晚上离开。满意了给你经验和钱，不满意扭头就走。你的整个经营循环，围着他们转。

## 游客怎么来

每天**清晨**，游客从道路端点沿路进镇——**只走铺好的路**。声望越高、殖民地等级越高，来的游客越多、越有钱。

| 项目 | 说明 |

| **精力** | 体力（0~200）。耗尽会去旅馆过夜或离城 |
| **满意度** | 好感度（0~100%），决定去留 |
| **等级** | 富裕等级（1~5）。越高越能花钱 |
| **钱包** | 这趟带来的金币 |

| **目标** | 正前往的建筑 |
| **行程** | 最近去过哪 |

## 游客的一天

1. **进镇**：沿路走向商店、景点。
2. **消费**：逛商店买商品，小镇赚元素；接受服务小镇拿元素反哺。
3. **过夜**：精力不足或入夜，去**旅馆**住下（要空房），清晨退房精力回满。
4. **离城**：满意度 **50% 以下**提前走；满意的待到晚上；**100% 满意**离开的会给小镇**经验**。

## 法师游客

约 **5% 的游客是法师游客**。满意度到 **100%** 的会在[酒馆](guide:tavern_guide)留简历——免费招募，攒法师靠这个。

## 怎么伺候好他们

- **路修好、建筑建齐**，游客才有地方逛、有东西买。
- 提高建筑的三值（舒适 / 魔法 / 奇观），游客更容易满意。
- 商店和旅馆机制正在重做，细节等更新。
