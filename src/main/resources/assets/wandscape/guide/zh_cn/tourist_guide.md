# 🧳 游客

游客是小镇的摇钱树，也是最难伺候的客人：他们清晨沿路进镇，逛够了自己会走。你的整个经营循环，都围着这几根需求条转。

## 游客想要什么

游客有三条**需求条**：**舒适 / 魔法 / 奇观**。他们会去能填满这些条的地方——逛商店买东西、去服务建筑、泡澡放松，把条一条条填满。

每个游客还有个**画像**：偏爱舒适、偏爱魔法或偏爱奇观（一眼看过去就是"这家店合我口味"和"这家店完全不懂我"的区别）。他们会优先去喂饱自己偏好的那条。

| 项目 | 说明 |

| **需求条** | 舒适 / 魔法 / 奇观三条，当前和需要的量 |
| **精力** | 体力。交互会消耗，精力耗尽就只能去放松建筑 |
| **等级** | 富裕等级（1~5）。越高越能花钱，需求也越高 |
| **钱包** | 手里的钱 |
| **停留** | 已经住了几晚、计划总共呆几天 |
| **行程** | 去过哪些建筑，每次的收益（舒适+X 魔法+Y 奇观+Z · 精力+W） |

## 游客的一天

1. **进镇**：清晨沿路进镇——**只走铺好的路**。
2. **逛**：自动挑最合适的地方去（按"需求缺口 + 精力 + 钱包"算，谁最缺就去谁）。商店买东西、服务建筑接受服务、澡堂泡澡、取款机取钱。
3. **过夜**：入夜还没逛够，去**旅馆**睡一晚，清晨精力回满继续逛。
4. **离场**：**三条需求条全满**的游客，晚上心满意足地离开——这时小镇获得**经验**。没逛够的也会走，但一分经验不给。

游客会逗留 **2~4 天**，整个停留期间一栋建筑只逛一次——所以别指望靠一两家店喂饱所有人。

## 三种"补给站"

- **放松建筑**（澡堂等）：**回复精力**。精力耗尽、又不想离场的游客会直奔这里。
- **取现建筑**（自动取款机）：**补充钱包**。旅费花光还没逛够的游客来这里取钱继续逛。
- **旅馆**：过夜恢复精力，见[旅馆指南](hotel_guide.md)。

这三样配齐，游客才能在小镇里把需求条填满、满意离场。

## 排队与容量

一栋建筑能**同时接待几个游客**，取决于它有几个**交互位**（就是游客做动作的那个位置）。位置全满，后来的游客排队；排太久等不及就走。想多接客？多放几个交互位，或者多盖几栋同类型的。

## 法师游客

约 **5% 的游客是法师游客**。三条需求条全满的法师游客会在[酒馆](tavern_guide.md)留简历——免费招募，攒法师靠这个。

## 怎么把小镇伺候好

- **路修好、建筑建齐**：商店、服务、放松、取现，各种建筑都来点，游客才有地方逛。
- **建筑三值对路**：建筑带的舒适/魔法/奇观值，决定了能喂饱哪条需求条、喂多快。
- **互动位和道路要够**：位子够、路通，游客逛得顺，满意离场的就多。
