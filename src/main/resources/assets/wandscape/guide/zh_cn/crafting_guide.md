# 🔨 合成台

合成台只干一件事：**造法杖**。法杖决定法师的战斗力，所以它值得单独占一章。

## 用起来

放置合成台，**右键**打开面板：挑一把法杖图纸（可按名字搜）→ 设数量 → **Submit**。任务队列面板会显示法师的制作进度——一根法杖要引导约 **1 分钟**，批量做要排队，等等就好。

## 法杖一览

| 法杖 | 需要殖民地等级 | 成本 | 法术强度加成 |
| :--- | :--- | :--- | :--- |
| **基础法杖** | 1 级 | 土 ×16 | +0 |
| **进阶法杖** | 3 级 | 土 ×32 + 金 ×16 | +0.5 |
| **大师法杖** | 5 级 | 金 ×64 + 暗 ×32 | +1.0 |

法术强度直接决定法师施法威力。配方有等级门槛，殖民地等级不够时配方锁着——先去把小镇经营升级。

## 几个提示

- 做好的法杖进**仓库**，在[法师面板](guide:npc_guide)给法师装上。
- 法杖不耗耐久，造一把用一辈子。
- 金和暗元素比较金贵，大师法杖是后期的东西，别急。
