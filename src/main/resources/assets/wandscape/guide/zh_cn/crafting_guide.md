# 🔨 合成台

制造**法杖**的专用设施。法杖决定法师的战斗力。

## 操作

放置合成台 → **右键**打开面板 → 挑选法杖图纸（可按名字搜） → 设数量 → **Submit**。

任务队列面板显示法师的制作进度。一根法杖需引导约 **1 分钟**，批量制作按队列顺序进行。

## 法杖属性

| 法杖 | 需要殖民地等级 | 成本 | 法术强度加成 |
| :--- | :--- | :--- | :--- |
| **基础法杖** | 1 级 | 土 ×16 | +0 |
| **进阶法杖** | 3 级 | 土 ×32 + 金 ×16 | +0.5 |
| **大师法杖** | 5 级 | 金 ×64 + 暗 ×32 | +1.0 |

法术强度直接决定法师施法威力。配方有等级门槛，殖民地等级不足时对应配方锁定。

## 提示

- 做好的法杖进**仓库**，在[法师面板](npc_guide.md)给法师装上。
- 法杖不耗耐久。
- 金和暗元素消耗较大，大师法杖属于后期配方。
