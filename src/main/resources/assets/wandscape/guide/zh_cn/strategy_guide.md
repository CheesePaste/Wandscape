# ⚔️ 施法策略

法师打架时放什么魔法，由策略决定。你不设也没关系——法师会按默认的来。但设一下，你的法师会聪明很多。

打开方式：**右键法师 → 信息屏 → 「策略」按钮**。

## 两层：预设 + 细调

**第一层 · 总体预设**（顶部 4 个按钮），决定施法的优先顺序：

| 预设 | 施法顺序（高 → 低） |
| :--- | :--- |
| **均衡** | 群体攻击 → 单体攻击 → 增益 → 防御 |
| **火力** | 单体攻击 → 群体攻击 → 防御 → 增益 |
| **支援** | 增益（治疗优先）→ 防御 → 群体攻击 → 单体攻击 |
| **防御** | 防御 → 增益 → 群体攻击 → 单体攻击 |

**第二层 · 分类内细调**：第二排分类按钮（**单体攻击 / 群体攻击 / 防御 / 增益**）切到某个分类，能看到法师**已会的魔法**：

- **开关**：启用 / 停用，停用的永远不放。
- **↑ / ↓**：调同一分类内已启用魔法的先后。

## 机制细节

- 自动施法时，按「预设顺序 + 分类内顺序」从高到低扫，挑**第一个能放**的：目标有效、冷却已过、魔力够。
- **改动即保存**，不用点确认。
- 一旦你配过某个法师（动过开关或顺序），就用你配的；没配过的按预设推。
- 祭坛魔法（如复活）不在自动施法里——那是[祭坛](altar_guide.md)的事。
