# ⚔️ 施法策略（Cast Strategy）使用指南

施法策略控制法师在**战斗中的自动施法**：只调一个「策略/优先级」维度，不写脚本。打开方式：**右键法师 → 信息屏 →「策略」**。

---

## 🎯 两层模型

策略分两层：**总体预设**决定分类的优先级顺序，**分类内魔法**可逐个启用/停用并调整顺序。

### 第一层：总体策略预设（顶部 4 个按钮）

| 预设 | 分类优先级（高 → 低） |
| :--- | :--- |
| 均衡 | 群体攻击 > 单体攻击 > 增益 > 防御 |
| 火力 | 单体攻击 > 群体攻击 > 防御 > 增益 |
| 支援 | 增益（治疗优先）> 防御 > 群体攻击 > 单体攻击 |
| 防御 | 防御 > 增益 > 群体攻击 > 单体攻击 |

### 第二层：分类内魔法

- 第二排 4 个分类按钮（**单体攻击 / 群体攻击 / 防御 / 增益**），点击切换当前查看的分类。
- 每个分类列出法师已知的魔法，一行一个：
  - **开关按钮**（On/Off）：启用 / 停用该魔法。停用的魔法不参与自动施法。
  - **↑ / ↓ 箭头**：调整**同一分类内已启用魔法**的先后顺序（停用的行不可移动）。

---

## ⚙️ 机制细节

- **自动施法流程**：按「预设的分类顺序 + 各分类内启用顺序」拼接成扁平优先级，从高到低选**第一个可施放**的魔法（需满足目标规则、条件、冷却与蓝量）。
- **改动即保存**：任何改动（点预设 / 开关 / 上移 / 下移）都会立即发送到服务端保存，无需手动确认。
- **显式优先级**：一旦配置过该法师的策略（点过开关或调过顺序），自动施法将使用你配置的显式优先级，不再按纯预设推导。
- **祭坛魔法不参与**：祭坛专属魔法（如复活）只允许在祭坛施放，法师自动战斗永远不会选中它们。
