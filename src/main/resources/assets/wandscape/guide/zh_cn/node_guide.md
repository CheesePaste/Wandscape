# ⛏️ 元素节点

产出元素的采集设施。法师会自动到节点采集，将元素送入仓库。

## 元素与节点

小镇有 **7 种元素**：**土 / 木 / 水 / 火 / 金 / 风 / 暗**。每种元素都有对应的节点建筑（火焰节点、暗元素节点等），**每种节点固定产出一种元素**。

## 操作

放置节点 → **右键**打开面板：

- 面板显示该节点产出物、单次采集量、吟唱时长。
- 滑条设**采集数量**（1~10），面板会算出总产量。
- 点**发布采集**，法师前来引导吟唱。**数量越大，吟唱越久**，单次产出也更多。
- 右侧任务队列显示采集中的法师，可取消或调整顺序。

## 提示

- 节点建成后自动发布采集任务；仓库元素低于日耗时，系统自动**加派高优先采集**补货。
- 采集结果进入**仓库**，在[仓库面板](warehouse_guide.md)查看存量。
- 缺哪种元素就多建对应节点；急用时可用[工作站](workstation_guide.md)分解补充。
