# ⛏️ 元素节点

元素是小镇的货币，节点就是铸币厂。法师会自动到节点采集，把元素源源不断送进仓库——你只管建，剩下的他们干。

## 元素是啥

小镇有 **7 种元素**：**土 / 木 / 水 / 火 / 金 / 风 / 暗**。每种元素都有对应的节点建筑（火焰节点、暗元素节点……），**每种节点固定产出一种元素**——想采什么，就建什么节点。

## 用起来

放置节点，**右键**打开面板：

- 面板显示这个节点产什么、每次采多少、吟唱多久。
- 滑条设**采集数量**（1~10），面板会算好总产量。
- 点**发布采集**，法师就会来，引导吟唱——**数量越大吟唱越久**，但一次拿得多。
- 右侧任务队列能看谁在采、取消或调整顺序。

## 几个提示

- 节点建成后自动发布采集任务；仓库元素低于日耗时，系统还会自动**加派高优先采集**补货——缺元素时的救命稻草。
- 采集进的是**仓库**，去[仓库面板](guide:warehouse_guide)看存量。
- 缺哪种元素就多建几个对应节点；急用就[工作站](guide:workstation_guide)分解。
