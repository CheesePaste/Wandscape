# 🚀 新手入门：从空城到游客小镇

从空地到能赚钱的魔法小镇，分八步完成。建造、采集、合成都由法师自动执行，你需要做的是决定盖什么、盖在哪。

> 全程随时按 **H** 键打开本指南，按 **V** 键打开面板。

---

## 第一步：放下市政厅

按 **V** 打开面板 → 左侧**建造**图标 → 【市政厅】分类 → 选中市政厅，**双击**进入放置 → 幽灵预览跟随鼠标移到空地上，点右侧「**📌 锁定**」（或按 **Enter**）固定位置 → 点「**✓ 提交施工**」打开施工界面 → **Submit** 建造。

市政厅是殖民地的核心，必须先建。建成后在**鸟瞰视角下左键**点击它给小镇命名，殖民地即算成立。

> 多数建筑**首次建造免费**（建造栏标有「首建免费」）。放下第一座建筑时，仓库自动收到**每种元素各 2000** 的启动元素。

## 第二步：建仓库备料

建造面板【仓库/存储】分类里有**仓库（Warehouse）**，建一个。

仓库存放小镇的全部元素与物资，NPC 建造、合成、采集都从这里取料。打开仓库可查看 **7 种元素**（土 / 木 / 水 / 火 / 金 / 风 / 暗）的存量。把背包里的建材存入仓库，供法师使用。

## 第三步：修路

游客**只走铺好的路**。没有路就没有游客，商店开门也不会有人进。

1. 按 **V** → 左侧**道路**图标。
2. 选**替换模式（REPLACE）**，双击选择路面材质。
3. **按住左键在地面拖框**选中要铺的区域，松开完成，**Enter** 铺路。
4. 需要弯道时用**样条线（SPLINE）**绘制，完成后由法师铺设。

## 第四步：建元素节点

元素是小镇的货币，建造、合成、维护费都要消耗。**元素节点**产出元素——每种节点固定产出一种，法师会自动采集。

鸟瞰视角下**左键**点节点打开面板，设定采集数量，点**发布采集**。哪种元素短缺，就多建对应的节点。

## 第五步：建生产工坊

建造面板【生产工坊】分类有两个设施：

- **合成台**制造**法杖**——法杖决定法师战斗力，分基础 / 进阶 / 大师三档，后两档需殖民地等级达标解锁。
- **工作站**将高级建材**分解**成元素（折价约 1/5，应急用），也能用元素**合成**高阶方块和装备。

## 第六步：建商店、旅馆和补给

游客通过消费填满三条需求条（舒适 / 魔法 / 奇观），需要配套建筑：

- **商店**：游客购买商品，小镇获得元素——见[商店指南](shop_guide.md)。
- **旅馆**：游客过夜恢复精力，并为小镇产出元素——见[旅馆指南](hotel_guide.md)。
- **放松建筑**（澡堂等）与**取款机（ATM）**：前者恢复精力、后者补充旅费，维持游客的停留与消费。

## 第七步：建酒馆，招募法师

法师通过**酒馆**招募：

- 酒馆的「招募 NPC」按钮**立即雇一名法师**（属性按小镇当前等级掷点）。每殖民地**首次免费**，之后每次消耗 7 种元素各 10000。
- 另有约 **5%** 的游客是法师游客：他们**三条需求条全满**时会在酒馆留下简历，可**免费**招募。

## 第八步：升级与声望

游客**三条需求条全满**时，夜晚满意离场，小镇获得经验。经验满后市政厅**升级**，解锁高级建筑并提高人口上限。游客越满意，积累的**声望**越高，之后进城的游客越富有。

## 维护费

每天结算时每座建筑消耗**维护费**（元素）。仓库元素耗尽，建筑会**停运**。V 面板侧栏的 ⚠️ 图标列出停运与损坏的建筑，可集中处理。为保持平稳运营，仓库应常备一定元素储备。
