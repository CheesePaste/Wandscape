# 🚀 新手入门：从空城到游客小镇

从一块空地到一座能赚钱的魔法小镇，其实只需要八步。别慌——每一步都有人替你干活，你只负责决定盖什么、盖在哪。

> 全程随时按 **H** 键打开本指南，按 **V** 键打开面板。

---

## 第一步：放下市政厅

按 **V** 打开面板 → 左侧**建造**图标 → 【市政厅】分类 → 选中市政厅，**双击**进入放置，**右键**固定并打开施工界面，**Submit** 建造。

市政厅是小镇的大脑，没有它你就不算建了小镇，只是堆了一堆建筑。建成后**右键它**，给你的小镇起个名字——这就算开张了。

（顺带一提：多数建筑的**首次建造免费**，建造栏会给你标出「首建免费」提示。放第一座建筑时，仓库会自动收到**每种元素各 2000** 的启动资金，别乱花。）

## 第二步：建仓库备料

建造面板【仓库/存储】分类里有**仓库（Warehouse）**，建一个。

所有钱和物资都从仓库过：NPC 建造、合成、采集都要从这取料。打开仓库能看到小镇的 **7 种元素**（土 / 木 / 水 / 火 / 金 / 风 / 暗）存量。把背包里的建材存进去，法师才有料可用。

## 第三步：修路（这步最不能省）

游客**只走铺好的路**。没路，就没有游客，商店开门也没人进来。

1. 按 **V** → 左侧**道路**图标。
2. 选**替换模式（REPLACE）**，双击挑个路面材质（石砖路就挺好）。
3. 按 **C** 释放光标，**右键**定起点、**左键**定终点，**Enter** 铺路。
4. 想要弯道？用**样条线（SPLINE）**画，画完让法师铺。

## 第四步：建元素节点

元素是小镇的货币：建造、合成、维护费都要花。**元素节点**就是铸币厂——每种节点固定产出一种元素，法师会自动来采。

右键节点面板，设定采集数量，点**发布采集**就行。缺哪种元素，就多建几个对应节点。

## 第五步：建生产工坊

建造面板的【生产工坊】分类里有两件大事：

- **合成台**造**法杖**——法杖决定法师的战斗力，基础/进阶/大师三档，后两档要殖民地等级够才能解锁。
- **工作站**把用不上的高级建材**分解**成元素（约打 1/5 折，应急用），也能用元素**合成**高阶方块和装备。

## 第六步：建商店、旅馆和补给

游客要在这里把三条需求条（舒适/魔法/奇观）填满，得有几样配套建筑：

- **商店**：游客买东西，你赚元素——见[商店指南](guide:shop_guide)。
- **旅馆**：游客过夜恢复精力，也给小镇产元素——见[旅馆指南](guide:hotel_guide)。
- **放松建筑**（澡堂等）和**取款机（ATM）**：前者回精力、后者补旅费，游客逛得动、有钱花，才不会中途离场。

## 第七步：建酒馆，招募法师

法师不是天上掉下来的，去**酒馆**招：

- 酒馆的「招募 NPC」按钮**立即雇一名法师**（按小镇当前等级掷点）。每殖民地**首次免费**，之后每次要 7 种元素各 10000——攒家底靠这个。
- 另外有约 5% 的游客是法师游客：他们**三条需求条全满**会在酒馆留简历，**免费**收编。

## 第八步：升级与声望

游客**三条需求条全满**的，夜晚满意离场，小镇获得经验；经验满市政厅**升级**，解锁高级建筑、提高人口上限。游客越满意，积累的**声望**越高，以后进城的游客就越富有。这是一个正循环：小镇越好→游客越满意→小镇越好。

## 别忘了：维护费

每天结算，每座建筑要交**维护费**（元素）。仓库空了，建筑就**停运**。V 面板侧栏的 ⚠️ 图标会列出停运和损坏的建筑，一键处理。想平稳经营，仓库里永远留点底。
