# 替换模式

用于日常铺路：框选一块地面，将地表的草、泥土、沙石直接替换为选定的路面材质。

## 三步铺一段路

1. 进模式：按 **V** → **道路**图标 → 模式栏选**替换（REPLACE）** → 双击底部卡片挑材质。
2. 框选：鼠标瞄准地面，**按住左键拖框**选中要铺的区域（起点亮红点，拖动拉出绿色选区），松开即完成。
3. 提交：检查选区后按 **Enter**。NPC 法师会执行铺设，完成后即为可通行道路。

选错了？**Backspace** 撤销上一步，或直接重新拖框覆盖。铺路射程约 **64 格**，超出范围需飞近后再选。

## 常见问题

**起点选错？** **Backspace** 撤销，或重新按住左键拖一个框覆盖。

**铺错位置？** 切**清理（DESTROY）**模式，按参照方块拆掉。
