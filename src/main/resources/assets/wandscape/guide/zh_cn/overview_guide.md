# 🏰 全局面板与鸟瞰视角

按 **V** 打开的面板，是你管理小镇的总指挥台。第一次打开可能有点懵——满屏图标和按钮，别怕，三分钟就熟了。

打开时默认进入**鸟瞰视角**：镜头从你的头顶升起，你可以俯瞰整个小镇，像下棋一样放置建筑、巡视街道、查看统计。

## 快捷键

| 按键 | 作用 |
| :--- | :--- |
| **V** | 打开 / 关闭面板 |
| **G** | 鸟瞰视角 ↔ 地面视角 切换 |
| **C** | 锁定 / 释放鼠标光标（释放后才能点面板 UI） |
| **B** | 显示 / 隐藏建筑占地边界红框 |
| **H** | 打开帮助文档 |

## 鸟瞰视角怎么飞

- **移动鼠标**转动视角，**WASD** 前后左右平移，**空格 / Shift** 升降，**滚轮**推进拉远。**Ctrl + 滚轮**调速。
- 想细看哪栋楼，飞近一点就行；镜头速度嫌慢就滚两下滚轮（按着 Ctrl）。

## 侧栏三件套

- **建造**：下方建筑栏按分类列出所有能盖的建筑（全部 / 市政厅 / 仓库存储 / 服务旅店 / 商业商店 / 放松 / 取现 / 生产工坊 / 元素节点）。**单击**选中、**双击**进入放置，世界里**左键**转朝向、**右键**固定并打开施工界面，微调 X/Y/Z 后 **Submit**。首建免费的会标出来。
- **道路**：铺路工具全家桶，详见[道路系统总览](road_guide.md)。
- **统计**：游客流向、经济收益、居民数量、异常警告，一眼扫完小镇状态。

侧栏下方还有个 **⚠️ 警告图标**：有建筑停运或损坏时会亮。点开就是[建筑故障报告](anomaly_guide.md)，坏了的建筑在这里一键修。

## 从哪开始

1. 建**市政厅**，创建殖民地。
2. 建**仓库**，存料。
3. 用道路工具把建筑连起来——游客只走铺好的路。

完整路线见[新手入门](getting_started_guide.md)。
