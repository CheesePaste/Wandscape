# 🏰 全局面板与鸟瞰视角

按 **V** 打开的面板用于管理小镇：放置建筑、铺设道路、查看统计。打开时默认进入**鸟瞰视角**，镜头升到上空俯瞰整个小镇。

## 快捷键

| 按键 | 作用 |
| :--- | :--- |
| **V** | 打开 / 关闭面板 |
| **G** | 鸟瞰视角 ↔ 地面视角 切换 |
| **B** | 显示 / 隐藏建筑占地边界红框 |
| **H** | 打开帮助文档 |

## 鸟瞰视角飞行

飞行操作与创造模式一致：**WASD** 平移、**空格 / Shift** 升降、**滚轮**缩放。需要细看某栋建筑时飞近即可；按住 **Ctrl + 滚轮** 调整飞行速度。

**按住右键拖动**旋转镜头——镜头始终自由，光标在面板 UI 与世界中自由移动，不需要切换模式。

## 侧栏三个页签

- **建造**：下方建筑栏按分类列出可盖建筑（全部 / 市政厅 / 仓库存储 / 服务旅店 / 商业商店 / 放松 / 取现 / 生产工坊 / 元素节点）。流程：**单击**选中 → **双击**进入放置 → 幽灵预览跟随鼠标移动 → 点右侧面板「**📌 锁定**」或按 **Enter** 固定位置 → 拖 **3D 坐标轴**微调、点「**↺ 旋转**」调朝向 → **双击幽灵建筑**（或用鼠标指准它点「**✓ 提交施工**」）打开施工界面 → **Submit** 建造。锁定状态按 **Esc** 回到瞄准，再按 **Esc** 退出放置。首建免费的建筑会在栏中标出。
- **道路**：铺路工具，详见[道路系统总览](road_guide.md)。
- **统计**：游客流向、经济收益、居民数量、异常警告。

侧栏下方的 **⚠️ 警告图标**在有建筑停运或损坏时亮起，点开为[建筑故障报告](anomaly_guide.md)，可在此修复损坏的建筑。

## 与建筑 / 法师交互

鸟瞰视角下**左键单击**建筑或法师打开对应面板（市政厅命名、商店备货、节点采集、法师装备与策略等）。右键不再用于交互——它负责旋转镜头。

## 从哪开始

1. 建**市政厅**，创建殖民地。
2. 建**仓库**，存料。
3. 用道路工具把建筑连起来——游客只走铺好的路。

完整路线见[新手入门](getting_started_guide.md)。
