# 🏰 Wandscape 全局控制面板与鸟瞰视角（Overview Panel Guide）

欢迎使用 Wandscape 魔法小镇控制面板！按下 **`V`** 键即可随时打开/关闭本面板。

---

## 🎮 1. 核心视角与快捷键

| 操作 / 按键 | 功能说明 |
| :--- | :--- |
| **`V` 键** | 打开 / 关闭 Wandscape 全局控制面板 |
| **`G` 键** | 在 **鸟瞰视图 (Overview)** ↔ **地面投影视图 (Ground Mode)** 之间快速切换 |
| **`C` 键** | 解锁 / 锁定鼠标光标（光标解锁后可自由点击面板 UI 标签） |
| **`B` 键** | 开关魔法小镇建筑占用领地边界红框显影 |
| **`H` / `F1` 键** | 打开当前模式的内置详细帮助文档 |
| **鼠标右键** | 在鸟瞰模式下长按并拖拽移动视角 |
| **`WASD` 键** | 在鸟瞰模式下平移自由飞行视角 |
| **鼠标滚轮** | 在鸟瞰模式下放大 / 缩小视角镜头 |

---

## 🏛️ 2. 面板三大核心功能板块（侧边栏选项卡）

通过侧边栏可随时切换以下三个功能：

1. **🏛️ 建造模式（Build Mode）**：
   - 包含市政厅、仓库、住宅、商店、民俗、基础设施等各类可建造建筑物。
   - 在下方建筑栏中 **单击建筑卡片** 选中建筑，**双击** 收回鼠标进入放置；世界中 **左键** 旋转方向，**右键** 固定虚影并打开「施工 UI」，可微调 **X/Y/Z 坐标** 后 **Submit** 建造。

2. **🛣️ 道路系统（Road Mode）**：
   - **自动铺路/单点铺路**：选择道路材质预设，连接建筑与主干道。
   - **样条线编辑器（Spline Editor）**：点击 Spline 按钮调出 3D 样条线贝塞尔曲线编辑器，轻松绘制弯道与立交桥。

3. **📊 魔法小镇统计（Stats Mode）**：
   - 实时查看当前魔法小镇的游客流向、经济收益、居民数量与异常状态警告。

---

## 🚩 3. 新手起步建议

1. **第一步**：建造 **市政厅（Town Hall）**，吸引法师 NPC 加入并管理魔法小镇。
2. **第二步**：建造 **仓库（Warehouse）**，用于存放建筑材料与生产物资。
3. **第三步**：使用 **道路工具（Road）** 将建筑与城镇道路连接，吸引游客入城消费！
