# 🏰 全局面板与鸟瞰视角

按 **V** 打开的面板用于管理小镇：放置建筑、铺设道路、查看统计。打开时默认进入**鸟瞰视角**，镜头升到上空俯瞰整个小镇。

面板分为两种状态，理解它们就掌握了基本操作：

- **常态**（没有点任何页签）：鼠标留在游戏层，移动鼠标直接旋转镜头，屏幕中心的**准心**用来对准建筑或法师操作。
- **子模式**：指点开**建造 / 道路**页签后进入的施工状态。此时光标抬起、可自由点面板，旋转镜头改为**按住右键拖动**。统计、警告页签只是查看界面，操作方式与常态一致。

## 最常用的操作

1. **常态交互**：移动鼠标旋转镜头；把屏幕中心的**准心**对准建筑或法师，按**右键**打开对应面板（市政厅命名、商店备货、节点采集、法师装备与策略等）。
2. **子模式下旋转镜头**：**按住右键拖动**。光标抬起时，移动鼠标只会移动指针，旋转镜头要靠按住右键拖。
3. **旋转建筑朝向**：建造子模式里放置建筑时，**左键单击**虚影即可旋转朝向。
4. **快速切换模式**：按 **1 / 2 / 3 / 4** 直接切到 建造 / 道路 / 统计 / 警告。

## 快捷键

| 按键 | 作用 |
| :--- | :--- |
| **V** | 打开 / 关闭面板 |
| **1 / 2 / 3 / 4** | 快速切换 建造 / 道路 / 统计 / 警告 |
| **G** | 鸟瞰视角 ↔ 地面视角 切换 |
| **B** | 显示 / 隐藏建筑占地边界红框 |
| **H** | 打开帮助文档 |
| **Tab** | 抬起 / 收回光标（详见下文） |

## 鸟瞰视角飞行

飞行操作与创造模式一致：**WASD** 平移、**空格 / Shift** 升降、**滚轮**缩放。需要细看某栋建筑时飞近即可；飞行速度固定，可在模组配置 `panel.flySpeed` 调整。常态下移动鼠标即可旋转镜头；建造 / 道路子模式里则按住右键拖动。

## 侧栏三个页签

- **建造**：下方建筑栏按分类列出可盖建筑（全部 / 市政厅 / 仓库存储 / 服务旅店 / 商业商店 / 放松 / 取现 / 生产工坊 / 元素节点）。流程：**单击**选中 → **双击**进入放置 → 幽灵预览跟随鼠标移动 → **左键单击**旋转朝向 → 点右侧面板「**✓ 提交施工**」打开施工界面 → **Submit** 建造。位置需要微调时：点「**📌 锁定**」或按 **Enter** 固定位置，拖 **3D 坐标轴**移动后再「**✓ 提交施工**」。锁定状态按 **Esc** 回到瞄准，再按 **Esc** 退出放置。首建免费的建筑会在栏中标出。
- **道路**：铺路工具，详见[道路系统总览](road_guide.md)。
- **统计**：游客流向、经济收益、居民数量、异常警告。

侧栏下方的 **⚠️ 警告图标**在有建筑停运或损坏时亮起，点开为[建筑故障报告](anomaly_guide.md)，可在此修复损坏的建筑。

## 抬起 / 收回光标（Tab）

建造、道路子模式里光标默认抬起，可直接点侧栏、建筑栏和右侧面板，转镜头用按住右键拖动，一般用不到 Tab。若手动按 **Tab**：在建造子模式里是开 / 关建筑栏；其他状态则抬起或收回光标，让指针在面板 UI 与世界中自由移动。

## 从哪开始

1. 建**市政厅**，创建殖民地。
2. 建**仓库**，存料。
3. 用道路工具把建筑连起来——游客只走铺好的路。

完整路线见[新手入门](getting_started_guide.md)。
