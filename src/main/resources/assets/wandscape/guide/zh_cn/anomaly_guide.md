# ⚠️ 建筑故障与维护

小镇总会出事：建筑停运、墙壁被炸。好在大多数问题在「异常报告」里一键就能处理。

## 怎么打开

有建筑出问题时，**V 面板侧栏的 ⚠️ 警告图标**会亮起（还带数量）。点开是**异常报告**，列表列着所有出问题的建筑：

| 列 | 说明 |
| :--- | :--- |
| **建筑名称** | 谁出事了 |
| **状态** | `关闭`（停运）或 `损坏` |
| **操作** | `营业` 或 `修复` 按钮 |

## 两种问题

**关闭（维护费付不起）**：每天结算时按建筑类型扣维护费（元素），仓库空了就停运。停运的建筑不干活、不贡献。点「**营业**」从仓库补交就能重启。

**损坏（物理损毁）**：建筑被怪物、爆炸之类破坏超过约 **1/3**，判定损坏，不再贡献。点「**修复**」，系统调度法师按蓝图修缮。

## 怎么预防

- **仓库常留底**：多建[元素节点](guide:node_guide)采集，用[工作站](guide:workstation_guide)分解多余材料补元素。
- 损坏**不会自己修**——修复必须你点，别指望法师自觉。

顺带一提：扫描器导出的 **custom 建筑没有维护费**，永远不会因为交不起钱停运。
