# 建筑状态

建筑**不会因损坏或手动关闭而停摆**——被怪物、爆炸打坏只是外观缺块，建筑照常运转、照常贡献。缺失的方块可通过 V 面板手动「修复」补齐。

## 查看建造进度

点开 V 面板侧栏的**警告图标**，可查看仍在建造中的建筑（等待材料 / 建造中阶段）：

| 列 | 说明 |
| :--- | :--- |
| **建筑名称** | 还在建造中的建筑 |
| **状态** | 等待材料 或 建造中 |

## 修复建筑

- 用 V 面板打开俯瞰视角，准心对准建筑，信息框下方有「**修复**」按钮。
- 点「修复」后，系统调度法师按蓝图补齐缺失方块（需要仓库有对应元素/材料）。
- **损坏不会自动修复**：必须由你点「修复」触发。
- 受损建筑不修复也能照常使用，只是外观缺块。
