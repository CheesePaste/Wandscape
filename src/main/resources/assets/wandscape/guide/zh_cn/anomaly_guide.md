# ⚠️ 建筑故障

建筑停运或损坏时，通过「异常报告」处理。大多数问题可一键解决。

## 打开方式

建筑出问题时，**V 面板侧栏的 ⚠️ 警告图标**亮起并显示数量。点开即为**异常报告**，列出所有出问题的建筑：

| 列 | 说明 |
| :--- | :--- |
| **建筑名称** | 出问题的建筑 |
| **状态** | 关闭（停运）或损坏 |
| **操作** | 营业或修复按钮 |

## 两类问题

**关闭（手动或结构损坏）**：玩家手动关闭，或因结构损坏而停运。停运的建筑不工作、不贡献。点「**营业**」即可重启。

**损坏（物理损毁）**：建筑被怪物、爆炸等破坏超过约 **1/3** 时判定损坏，不再贡献。点「**修复**」，系统调度法师按蓝图修缮。

## 预防

- **仓库常备元素储备**：多建[元素节点](node_guide.md)采集，用[工作站](workstation_guide.md)分解多余材料补充元素。
- **损坏不会自动修复**：必须由你点「修复」触发。
