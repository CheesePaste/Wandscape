# 🛣️ 道路系统

先说个残酷的事实：**游客只走铺好的路**。你修的路能延伸多远，小镇的经济就能长多远——这不是比喻，是硬规则。所以这篇值得认真读。

![道路系统示意图](wandscape:textures/gui/guide/road_diagram.png =200x100)

## 进入道路模式

按 **V** 打开面板 → 左侧**道路**图标。底栏挑材质，模式栏挑工具。**C** 键在「面板光标」和「准心视线」之间切换：点 UI 用光标，世界里选点用准心。

## 四种模式

| 模式 | 用法 | 什么时候用 |
| :--- | :--- | :--- |
| **替换 REPLACE** | 右击定起点，左击定终点，框一块矩形 | 日常铺路：把草地泥土换成路面 |
| **填充 FILL** | 选两个对角点，拉出立体方块 | 高架桥、填深坑、搭基座 |
| **清理 DESTROY** | 右击抓一个参照方块，再框范围 | 拆错铺的方块、整平地形 |
| **样条线 SPLINE** | 打开编辑器，在世界里点锚点画曲线 | 弯道、环形路、立交 |

## 材质

双击底栏卡片挑选：**土径 / 道路（石质）/ 草 / 水面 / 圆石 / 沙砾 / 橡木木板**。

## 通用操作（替换 / 清理模式）

| 操作 | 作用 |
| :--- | :--- |
| **右键** | 定起点（再按一次全清重选） |
| **左键** | 定终点 |
| **Enter** | 提交，发布铺路任务 |
| **Backspace** | 撤销上一个端点 |
| **ESC** | 退出道路施工 |

提交后 NPC 法师会照任务自动铺；建筑放得够多时，小镇也会自动规划道路把建筑连起来。要画精细的弯道和立交，用[样条线编辑器](road_spline_guide.md)。
