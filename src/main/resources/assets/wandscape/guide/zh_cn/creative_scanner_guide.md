# 🛠️ 创造建筑扫描器

这篇写给创作者和地图作者。**创造建筑扫描器是创造模式工具，生存模式拿不到**——它能把建筑连同**游客交互位、装饰实体、整套经营参数**一起导出，做出"有灵魂"的建筑。普通玩家用[建筑扫描器](scanner_guide.md)复制房子就够了。

## 结构配对

放两个方块：**SAVE（主）** 和 **CORNER（角点）**，填相同的结构名，64 格内自动配对算出包围盒，不用手动录坐标。

## 在面板里把建筑"装修"齐全

- **边界**：X/Y/Z 各 ±1 按钮微调包围盒大小。
- **门偏移**：自动检门，多扇门循环切换。
- **元数据**：建筑 ID、名称、制作者、舒适/魔法/奇观三值、解锁等级。
- **维护费**：按元素逐条添加每天消耗。
- **预设预存**：把整套配置存成预设，下次直接加载。

## 游客交互位（interact spots）

想让游客在建筑里**真的做动作**（而不是站桩发呆）？用 `interact_spot_marker` 方块在世界里标记一个"站位"：

- **放置**：往地上放一个 marker，就是一个交互位——立刻会有一个**预览假人**站上去，循环演示这个位置的动作。
- **右键**：循环切换动作——**浏览 / 用餐 / 泡澡 / 看展 / 冥想 / 歇脚 / 取现**。
- **潜行右键**：循环切换朝向（北/东/南/西），游客做动作时会面朝这个方向。
- **敲掉**：移除该交互位。

几条约定：**交互位数量 = 同一时间最多能在这交互的游客数**（满了后面的人排队）；交互位占的那格在蓝图里自动留空，别把关键结构方块压在它下面；建筑旋转时，交互位朝向会跟着一起转。

## 装饰实体

物品展示框、画这类**实体**（不是方块）也能被扫进去：导出时会捕获它们的种类、朝向和内容，NPC 重建时原样还原。挂墙上的装饰从此不会丢。

## 四类游客建筑的经营参数

| 类别 | 能配什么 |
| :--- | :--- |
| **商店 shop** | 利润率、交互时长、**上架商品列表**（每件商品带舒适/魔法/奇观三值） |
| **服务 service** | 每次消耗游客多少精力、产出的元素、**最大住宿**（>0 就是旅店）、交互时长 |
| **放松 relax** | 每次恢复游客多少精力、交互时长 |
| **取现 atm** | 每次可取多少钱、交互时长 |

## 导出

配完点「**导出建筑 JSON**」——导出会带上交互位、装饰实体和整套经营参数，**立即在游戏内生效**，`/reload` 也在。
