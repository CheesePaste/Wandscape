# 🏗️ 建筑扫描器（Building Scanner）API 级指南

建筑扫描器用于扫描游戏内建造好的建筑/道路并**一键导出模组 JSON 蓝图与道路预设**，让 NPC 通过蓝图重建。现分两种：

- **创造建筑扫描器**（`creative_building_scanner`）：完整创作者工具，支持全部类别与完整配置。
- **建筑扫描器**（`building_scanner`）：专供生存玩家复制自己的建筑，类别固定为**自定义（custom）**，仅尺寸/门/ID/名称 + 导出。

## 🛠 创造建筑扫描器（Creative Building Scanner）

界面采用标准中世纪金边主题 (`MedievalScreen`) 与手绘渐变按钮 (`drawMinimalBox`)，输入框具有古铜金线边框与 **Focus / Hover 动态发光** 效果，且配置有原生视口裁剪（Scissor Clip），滑动时绝不出界。

### 1. 结构配对模式 (`BlockMode`)
- **`SAVE` (保存主控)**：主扫描器，负责计算包围盒、展示配置面板与执行 JSON 导出。
- **`CORNER` (辅角点)**：用于标记 3D 包围盒对角线顶点的辅助方块。
- **自动配对**：在 64 格范围内，填有相同 `Structure Name` 的 `SAVE` 与 `CORNER` 方块会自动配对算准 3D 包围盒，无需手动录入坐标。

### 2. 导出目标模式 (`TargetMode`)
- **`BUILDING` (建筑模式)**：
  - 展示完整建筑配置（门偏移 `Door Offset`、游览交互区 `Tourist Zones`、三值 `Comfort/Magic/Wonder`、解锁等级 `Unlock Level`、周期维护费 `Maintenance Cost` 以及商店/服务/节点特化参数）。
  - `Type (Category)` 可选全部类别，其中 **`custom`（自定义）** 代表无维护费、游客不可交互、三值恒 0。
  - 点击 **【导出建筑 JSON】** 将蓝图导出至 datapack 建筑目录并**在游戏内立即热注册**，`/reload` 后依然有效。
- **`ROAD` (道路模式 - 特化简化)**：
  - 自动隐去所有建筑专属配置，界面极为精简通透。
  - 仅保留 `Road Preset ID` 与 `Display Name`。
  - 点击 **【导出与热注册道路 JSON】** 导出并**在游戏内立即热注册生效**！

### 3. 关键操作
- **`自动检门`**：自动扫描 3D 包围盒内的门方块并填入门偏移，支持多门多次点击循环切换。
- **`扫描区域`**：统计 3D 包围盒内的非空气有效方块数量（**自动剔除所有扫描器方块本身**）。

## 🧱 建筑扫描器（Building Scanner）

专为生存玩家设计，用于把**自己建造的建筑复制一份**交给 NPC 重建（扫描器本身可通过合成台合成：四角金锭 + 上下左右紫水晶碎片 + 中间工作台）。

- **类别锁定为 `custom`（自定义）**：不可修改。
  - **无维护费**：每日结算跳过，永不因维护费关停。
  - **游客不可交互**：游客不会前往该建筑。
  - **三值恒 0**：`comfort/magic/wonder` 全为 0，对殖民地无贡献。
- **仅提供**：
  - **尺寸（boundary）**：手动设置 3D 包围盒 min/max。
  - **门偏移（Door Offset）**：设定 NPC 进入建筑交互的 Entry 坐标，支持自动检门。
  - **ID / 名称**：建筑唯一标识与显示名。
  - **导出**：`扫描区域` 统计有效方块，`导出建筑 JSON` 生成 custom 类别蓝图。
- **ROAD 模式同样保留**：可切换为道路预设导出。

### 3 步操作流程（生存）

1. **框选**：放置生存扫描器，手动设置尺寸包围盒覆盖你的建筑。
2. **标识**：填写建筑 ID（如 `player_castle`）与显示名称；用自动检门选门偏移。
3. **导出**：点击 **【导出建筑 JSON】**，聊天栏确认成功后即可让 NPC 按蓝图重建。
