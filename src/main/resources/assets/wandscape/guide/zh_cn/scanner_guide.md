# 🏗️ 建筑扫描器

把已建好的建筑变成蓝图，法师可在别处按蓝图重建。扫描器在**生存模式**可合成。

## 合成配方

四角**金锭**，上下左右**紫水晶碎片**，中间一个**工作台**。

## 扫描后的建筑

扫描器把建筑存成**自定义**类别：

- **游客不会来**——没有三值贡献，不参与经营。

这类建筑不产生收益、不吸引游客，仅用于复制玩家手建的建筑。

## 操作

1. **框选**：放下扫描器，在面板里手动设**尺寸包围盒**，把要复制的建筑整个罩住。
2. **标识**：给建筑起一个**英文 ID**（如 `player_castle`，之后用它选中蓝图）和**显示名称**；点「自动检门」选出门的位置——那是 NPC 进出的入口。
3. **导出**：点「扫描区域」统计方块，再点「**导出建筑 JSON**」。聊天栏提示成功后，这块建筑就是蓝图了，以后能在建造面板里选中它让 NPC 重建。

复制一段路：切到 **ROAD 模式**，填道路预设 ID 和显示名即可导出。

## 创造建筑扫描器

功能更全的**创造建筑扫描器**面向创作者和地图作者（能配交互位、经营参数、装饰导出），**生存模式拿不到**，相关配置在普通游玩中用不上。地图作者请见[创造建筑扫描器指南](creative_scanner_guide.md)。
