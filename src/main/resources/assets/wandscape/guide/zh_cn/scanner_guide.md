# 🏗️ 建筑扫描器

房子盖好了，想让 NPC 照着再盖一栋？扫描器把你的建筑变成蓝图，之后法师就能一模一样地重建。模组提供两种：

- **建筑扫描器**（可合成）：给生存玩家用，复制你自己的建筑。
- **创造建筑扫描器**（创造模式）：给创作者和地图作者，配置全，能把建筑连同**游客交互位、装饰、经营参数**一起导出。

## 建筑扫描器（生存玩家）

合成配方：四角**金锭**，上下左右**紫水晶碎片**，中间一个**工作台**。

它扫描出的建筑是**自定义（custom）**类别：**没有维护费**（永远不会因为交不起钱停运），**游客不会来**（没有三值贡献）——它不参与经营，纯粹是让你复制房子。

用法三步：

1. **框选**：放下扫描器，在面板里手动设**尺寸包围盒**，把要复制的建筑整个罩住。
2. **标识**：填建筑的 **ID**（唯一标识，如 `player_castle`）和**显示名称**；点「自动检门」选出门的位置——那是 NPC 进出的入口。
3. **导出**：点「扫描区域」统计方块，再点「**导出建筑 JSON**」。聊天栏提示成功后，这块建筑就是蓝图了，以后能在建造面板里选中它让 NPC 重建。

想复制一段路？切到 **ROAD 模式**，只要填道路预设 ID 和显示名就能导出。

## 创造建筑扫描器（创作者）

完整版工具。放两个方块——**SAVE（主）** 和 **CORNER（角点）**，填相同的结构名，64 格内自动配对算出包围盒。之后在屏幕上把建筑"装修"齐全：

- **边界**：X/Y/Z 各 ±1 按钮微调包围盒大小。
- **门偏移**：自动检门，多扇门循环切换。
- **游客交互位**：详见下节——建筑里游客站在哪儿逛、往哪看，都在这标记。
- **元数据**：建筑 ID、名称、舒适/魔法/奇观三值、解锁等级。
- **维护费**：按元素逐条添加每天消耗。
- **经营参数**：取决于建筑类别——商店/服务/放松/取现各有专属设置。
- **预设预存**：把整套配置存成预设，下次加载。

### 游客交互位（interact spots）

想让游客在建筑里**真的做动作**（而不是站桩发呆）？用 `interact_spot_marker` 方块在世界里标记一个"站位"：

- **放置**：往地上放一个 marker，就是一个交互位——立刻会有一个**预览假人**站上去，循环演示这个位置的动作。
- **右键**：循环切换动作——**浏览 / 用餐 / 泡澡 / 看展 / 冥想 / 歇脚 / 取现**。
- **潜行右键**：循环切换朝向（北/东/南/西），游客做动作时会面朝这个方向。
- **敲掉**：移除该交互位。

几条约定：**交互位数量 = 同一时间最多能在这交互的游客数**（满了后面的人排队）；交互位占的那格在蓝图里自动留空，别把关键结构方块压在它下面；建筑旋转时，交互位朝向会跟着一起转。

### 装饰实体

物品展示框、画这类**实体**（不是方块）也能被扫进去：导出时会捕获它们的种类、朝向和内容，NPC 重建时原样还原。挂墙上的装饰从此不会丢。

### 四类游客建筑的经营参数

| 类别 | 能配什么 |
| :--- | :--- |
| **商店 shop** | 利润率、交互时长、**上架商品列表**（每件商品带舒适/魔法/奇观三值） |
| **服务 service** | 每次消耗游客多少精力、产出的元素、**最大住宿**（>0 就是旅店）、交互时长 |
| **放松 relax** | 每次恢复游客多少精力、交互时长 |
| **取现 atm** | 每次可取多少钱、交互时长 |

配完点「**导出建筑 JSON**」——导出会带上交互位、装饰实体和整套经营参数，**立即在游戏内生效**，`/reload` 也在。
