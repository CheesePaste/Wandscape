# 🏗️ 建筑扫描器

房子盖好了，想让 NPC 照着再盖一栋？用建筑扫描器把你的建筑变成蓝图，之后法师就能一模一样地重建。这把扫描器能在**生存模式**合成，是给玩家自己的复制工具。

## 合成配方

四角**金锭**，上下左右**紫水晶碎片**，中间一个**工作台**。

## 它扫出来的建筑是啥样

扫描器把建筑存成**自定义（custom）**类别，两个特点：

- **没有维护费**——永远不会因为交不起钱停运。
- **游客不会来**——没有三值贡献，不参与经营。

说白了，它不赚钱、不吸引人，纯粹是让你把亲手建的房子复制一份，让 NPC 在别处重建。

## 用法三步

1. **框选**：放下扫描器，在面板里手动设**尺寸包围盒**，把要复制的建筑整个罩住。
2. **标识**：填建筑的 **ID**（唯一标识，如 `player_castle`）和**显示名称**；点「自动检门」选出门的位置——那是 NPC 进出的入口。
3. **导出**：点「扫描区域」统计方块，再点「**导出建筑 JSON**」。聊天栏提示成功后，这块建筑就是蓝图了，以后能在建造面板里选中它让 NPC 重建。

想复制一段路？切到 **ROAD 模式**，填道路预设 ID 和显示名就能导出。

## 创造建筑扫描器呢？

功能更全的**创造建筑扫描器**是给创作者和地图作者的（能配交互位、经营参数、装饰导出）——**生存模式拿不到**，而且那些配置对普通游玩也用不上。做地图的人可以去看[创造建筑扫描器指南](creative_scanner_guide.md)，玩家看到这就够了。
