# 🏗️ 建筑扫描器

房子盖好了，想让 NPC 照着再盖一栋？扫描器把你的建筑变成蓝图，之后法师就能一模一样地重建。模组提供两种：

- **建筑扫描器**（可合成）：给生存玩家用，复制你自己的建筑。
- **创造建筑扫描器**（创造模式）：给创作者和地图作者，配置全、能导出道路。

## 建筑扫描器（生存玩家）

合成配方：四角**金锭**，上下左右**紫水晶碎片**，中间一个**工作台**。

它扫描出的建筑是**自定义（custom）**类别，两个特点：**没有维护费**（永远不会因为交不起钱停运），**游客不会来**（没有三值贡献）——它不参与经营，纯粹是让你复制房子。

用法三步：

1. **框选**：放下扫描器，在面板里手动设**尺寸包围盒**，把要复制的建筑整个罩住。
2. **标识**：填建筑的 **ID**（唯一标识，如 `player_castle`）和**显示名称**；点「自动检门」选出门的位置——那是 NPC 进出的入口。
3. **导出**：点「扫描区域」统计方块，再点「**导出建筑 JSON**」。聊天栏提示成功后，这块建筑就是蓝图了，以后能在建造面板里选中它让 NPC 重建。

想复制一段路？切到 **ROAD 模式**，只要填道路预设 ID 和显示名就能导出。

## 创造建筑扫描器（创作者）

完整版工具，支持全部建筑类别和详细配置：

- **结构配对**：放两个方块——**SAVE（主）** 和 **CORNER（角点）**，填相同的结构名，64 格内自动配对算出包围盒，不用手动录坐标。
- **建筑模式**：门偏移、游客交互区、舒适/魔法/奇观三值、解锁等级、维护费、商店/服务/节点专有参数都能配。类别可选全部；其中 **custom** 就是上面说的"无维护费、游客不交互、三值恒 0"。导出后**立即在游戏内生效**，`/reload` 也在。
- **道路模式**：界面干净得多，只留道路预设 ID 和显示名，导出道路预设。
- **自动检门**：自动扫出包围盒里的门并填进门偏移，多扇门多按几次循环选。
