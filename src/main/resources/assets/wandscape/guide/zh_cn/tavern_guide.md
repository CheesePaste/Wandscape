# 🍺 酒馆

法师不是天上掉下来的——想招人，去酒馆。它有两个页签，对应两条招人路子。

## 招募 NPC

点「**招募 NPC**」按钮，立刻生成一名法师，属性按小镇**当前等级**掷点（可能掷出高属性专精，看脸）。

计费：每殖民地**首次免费**；之后每次要 **7 种元素各 10000**——不便宜，但法师是核心劳动力，这钱该花。

## 法师简历

约 **5% 的游客是法师游客**。他们满意度到 **100%** 会自愿留下简历。这里的法师**免费雇佣**——这是把小镇经营好的回报，也是攒法师的主力渠道。

## 几个提示

- 招募成功后法师满蓝入职，直接开始干活。
- 想多拿简历？去[游客指南](guide:tourist_guide)看看怎么让游客满意。
- 法师的属性、装备和战斗策略，见[法师 NPC 指南](guide:npc_guide)。
