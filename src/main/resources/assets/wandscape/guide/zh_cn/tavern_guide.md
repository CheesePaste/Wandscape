# 🍺 酒馆

招募法师的建筑，提供「招募 NPC」和「法师简历」两个页签。

## 招募 NPC

点「**招募 NPC**」按钮，立即生成一名法师，属性按小镇**当前等级**掷点。

| 项目 | 说明 |
|---|---|
| 首次 | 每殖民地**免费**一次 |
| 之后 | 每次消耗 **7 种元素各 10000** |
| 属性 | 按当前等级掷点，可能掷出高属性专精 |

## 法师简历

约 **5% 的游客是法师游客**。他们三条需求条**全满**时会在酒馆留下简历，可**免费雇佣**——这是攒法师的主力渠道。

## 提示

- 招募成功的法师满蓝入职，立即开始工作。
- 想增加简历来源：见[游客指南](tourist_guide.md)了解如何让游客填满需求条。
- 法师的属性、装备与战斗策略见[法师 NPC 指南](npc_guide.md)。
