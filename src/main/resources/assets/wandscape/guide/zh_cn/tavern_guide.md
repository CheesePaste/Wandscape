# 🍺 酒馆（Tavern）API 级详细指南

酒馆为游览魔法小镇的游客提供餐饮与休闲服务，并可招募高满意度法师！

---

## 📖 UI 控件与字段 API 级别明细字典 (UI Options API Reference)

| 控件标识 / 标签 | 类型 / 范围 | 默认值 | 详细作用机制与计算影响 |
| :--- | :--- | :--- | :--- |
| **`Tab 0: Recruit`** | Tab | — | 生成/招募普通法师 NPC 加入魔法小镇。**首次免费**，之后每次需每种元素 10000。 |
| **`Tab 1: Mages`** | Tab | — | **法师简历面板**。展示游览满意度达到 100% 并自愿留下的精锐法师游客简历。 |
| **`Recruit Button`** | MedievalButton | — | 支付雇佣金，正式将选中的法师招募为常驻魔法小镇劳工。 |
