# 📦 仓库

存放小镇全部元素与物资。建造、合成、维护从这里扣料，游客消费收入也回到这里。**材料存进仓库，NPC 才能取用。**

## 两个页签

**总览（Overview）**

| 项目 | 说明 |
|---|---|
| 元素面板 | 小镇储备的 **7 种元素**（土 / 木 / 水 / 火 / 金 / 风 / 暗）存量 |
| 物品列表 | 可搜索的物资清单，按名字模糊搜 |
| 物资缺口 | 合成台或工作站卡住时，缺的材料在此高亮 |

**存取（Exchange）**

点仓库物品**取出**，点背包物品**存入**，数量可调。

## 启动资金

放下第一座建筑时，仓库自动收到**每种元素各 2000** 的启动元素。

## 元素消耗

维护费、建造、合成都要消耗元素。元素短缺时靠[元素节点](node_guide.md)采集、或[工作站](workstation_guide.md)分解补充。

## 提示

> NPC 取料时会显示物品**飞行动画**，从仓库送到法师手里，属正常表现。
