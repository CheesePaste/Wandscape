# ⚙️ 工作站

把高级建材分解成元素，或用元素合成方块、装备和特殊物品。

## 分解

将高阶建材、矿石等还原成元素。

| 项目 | 说明 |
|---|---|
| 折价 | 返还约为原价值的 **1/5** |
| 定位 | 元素短缺时应急补充，不适合作为主要来源 |

## 合成

用元素 + 材料合成高阶方块、装备和特殊物品。配方受**殖民地等级**限制，等级不足的配方会锁定。

## 操作

**准心对准工作站，右键** → 选页签 → 挑配方 → 设数量 → **Submit**。任务进入队列由法师执行，进度在面板查看。

## 提示

- 合成消耗元素、分解返还元素，配合[元素节点](node_guide.md)采集可平衡元素收支。
- 配方锁定时会显示原因（等级不足 / 元素不足），按提示补足即可。
