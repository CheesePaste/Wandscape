# ⚙️ 工作站

工作站是元素的钱庄：把用不上的高级建材**拆**成元素，再把元素**合**成你需要的东西。拆是应急，合是消费，两头都能用。

## 两个页签

**分解（Decompose）**：把有元素价值的物品（高阶建材、矿物之类）还原成元素。注意有**约 1/5 的折价**——应急补元素可以，靠它发财没门。

**合成（Synthesize）**：用元素 + 材料合成高阶方块、装备和特殊物品。合成配方有殖民地等级门槛，等级不够的会锁着。

## 操作

右键工作站 → 选页签 → 挑配方 → 设数量 → **Submit**。法师在任务队列里干活，进度看面板就行。

## 几个提示

- **元素周转**：合成扣元素、分解补元素，配合[元素节点](guide:node_guide)采集，就能把元素收支盘活。
- 配方锁着的时候会显示原因（等级不够 / 元素不足），照着补即可，不用瞎猜。
