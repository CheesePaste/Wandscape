# 🏪 商店

商店是小镇赚钱的地方：游客在店里花钱买商品，你把元素收进仓库。看着简单，但它是整个经济的发动机——游客的需求条怎么填，很大程度上看商店。

## 商店怎么运转

- 商店的**商品列表**是建筑配置决定的：每种商品自带**舒适 / 魔法 / 奇观三值**（面包店卖吃的、花店卖花、书店卖书，各有各的口味）。
- 游客站到商店的**交互位**上"逛店"（那个小人真的会做出浏览的样子），按建筑设定的**交互时长**呆上一会儿。
- 游客花掉**旅费**，你按商品的元素价值和**利润率**把元素收进仓库——利润率高，同样一件商品赚得更多。
- 商品带的三值会填游客对应的**需求条**：舒适值高的商品喂饱爱舒适的人，魔法值高的喂饱爱魔法的人。商品配置得对，游客才满意。

## 你需要做的

**右键商店**打开面板，调每种商品的**最大备货量**（0~64）：货架就这么多，卖得快就多备点。系统会从仓库自动补货，备货量决定了商品能撑多久。

商店不是建好就完事——**要有交互位、商品要对路、要连得上路**。这一套做下来，商店才是真能赚钱的商店。

## 几种商店

模组自带面包店、花店、书店、魔法商店。想自己开新店？用[建筑扫描器](guide:scanner_guide)的商店模式配置商品和利润率，导出即生效。

（顺带一提：商店的商品列表在建筑 JSON 里定义——`goods` + `profit_rate` + 交互时长。面包店 6 种食品、花店 6 种花、书店 6 种书，各有侧重，开在不同街区能吸引不同画像的游客。）
