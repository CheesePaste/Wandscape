# ➰ 样条线道路制作工坊（Spline Road Studio）详细指南

样条线道路制作工坊（Spline Road Studio）是 Wandscape 最强大的道路建造工具。通过 ImGui 可视化面板，你可以在 3D 世界中实时添加、编辑、拖拽贝塞尔曲线控制点，打造优雅弯道、环形路与复杂立体道路，并支持与概览 (V) 面板选中的方块无缝联动与动态规格微调！

---

## 🚪 1. 如何进入与退出编辑器

### 进入方式
1. 按 **`V`** 打开 Wandscape 控制面板。
2. 点击左侧 **Road / 道路** 图标，进入道路工具。
3. 点击左侧工具栏 **`Spline`** 按钮。
4. V 面板自动关闭，ImGui 道路制作工坊随即在屏幕右侧弹出。

### 退出方式
- 按 **`ESC`** 键退出编辑器（不按住右键时）。
- 或点击 ImGui 面板底部的 **`关闭 Studio`** 按钮。

---

## 🎮 2. 视角控制（Camera Flight / 灵魂出窍模式）

进入编辑器后，玩家角色处于灵魂出窍（Freecam）状态，WASD 输入将被拦截（不会移动游戏内的玩家实体）。你可以通过以下方式自由飞行观察：

| 操作 | 功能 |
| :--- | :--- |
| **右键按住 + 移动鼠标** | 旋转视角（Yaw / Pitch） |
| **右键按住 + WASD** | 灵魂出窍 3D 飞行移动（沿视角方向飞行，游戏角色不动） |
| **右键按住 + Space** | 垂直向上飞行 |
| **右键按住 + Shift** | 垂直向下飞行 |
| **右键按住 + Ctrl** | 飞行加速（2 倍速） |
| **直接滑动鼠标滚轮** | 调节灵魂出窍飞行速度（0.02 ~ 5.0，无需按 Ctrl，Actionbar 实时显示提示） |
| **G 键** | 切换 2D 鸟瞰/俯视视角（Top-Down View） |
| **H 键** | 随时打开本操作指南 |

松开右键后，鼠标光标自动释放，可以操作 ImGui 面板或在世界中点选控制点。

## 🖱️ 3. 世界内交互（点选、添加、拖拽）

### 3.1 添加控制点（点击添加点 模式）
1. 在 ImGui 面板 **`🛣️ 曲线编辑`** 标签页中选择 **`➕ 点击添加点`**。
2. 松开右键（光标释放状态），将鼠标对准世界中的方块表面。
3. **左键单击** → 在该方块顶面创建一个新的样条线锚点（Anchor）。
4. 重复添加 2 个以上锚点，编辑器自动生成贝塞尔曲线预览。

### 3.2 选择控制点
- 在添加或编辑模式下，**左键单击** 已有的锚点球体即可选中。
- 选中后，该点周围显示 **RGB 三维轴 Gizmo**（红 = X、绿 = Y、蓝 = Z）。
- 在 **`🎯 选择与拖拽`** 模式下，还可以点选切线控制柄（前手柄 / 后手柄 小球体）。

### 3.3 三维轴拖拽（Axis Gizmo Drag）
选中控制点后：
1. 将鼠标悬停在某个轴箭头上（该轴会自动高亮）。
2. **左键按住拖拽** → 沿该轴方向平移选中的锚点或切线手柄。
3. 支持 6 个方向：X+、X-、Y+、Y-、Z+、Z-。
4. 拖拽时按住 **`Shift`** → 临时解除对称锁定（仅移动当前控制柄，不联动对侧）。

### 3.4 删除控制点
- 选中控制点后按 **`Delete`** 或 **`Backspace`** 删除。
- 或在 ImGui 面板节点属性检查器中点击 **`🗑️ 删除节点`** 按钮。

## 🖥️ 4. ImGui 面板三大选项卡详解

### 4.1 选项卡一：🛣️ 曲线编辑 (Curve Nodes)

#### 编辑模式切换
- **`➕ 点击添加点`**：左键点击世界方块表面顺序新建锚点。
- **`🎯 选择与拖拽`**：点选锚点/控制柄，通过 Gizmo 3D 轴控制曲线形状。

#### 曲线几何与平移
- **闭合环形道路 (连接首尾)**：勾选后首尾相连，构建无缝闭合环路。
- **整体平移 (X, Y, Z)**：输入 X, Y, Z 增量后点击 **`整体平移`**，整条曲线所有点一并移动。

#### 控制点列表 & 节点属性检查器
- **控制点列表**：滚动查看所有锚点坐标与对称状态（`[对称]` / `[自由]`），点击项目可快速选中。
- **调整句柄目标**：可在 `主锚点`、`前手柄`、`后手柄` 间切换。
- **三维精确坐标**：可输入精确浮点数值微调位置。
- **对称切线手柄锁定**：勾选后前后手柄镜像联动，保证弯道平滑。
- **📷 视角聚焦**：一键将自由视角平移至选中控制点附近。
- **🗑️ 删除节点**：删除当前选中的控制节点。

---

### 4.2 选项卡二：🧊 阵列生成 (Array Studio)

#### 模板来源与 V 面板联动（核心功能）
支持两种模板生成模式：
1. **V 面板方块预设 (推荐)**：
   - 与概览 (V) 面板选中的道路预设（如 `土径`、`路面`、`草方块`、`水源`、`圆石`、`砂砾`、`橡木木板`）**强联动**。在 ImGui 中切换方块会实时同步更新 V 面板！
   - **动态道路规格生成器**：
     - **道路宽度 (Width)**：自由滑动调节横向铺设方块宽度（`1 ~ 15` 格）。
     - **基层厚度 (Depth)**：自由滑动调节垂直向下铺设的基础层数（`1 ~ 3` 层）。
     - **加装路肩石边 (Side Border)**：勾选后道路左右最外侧边缘自动铺设石砖护栏包裹修饰。
2. **JSON 预设文件**：
   - 读取硬盘中保存的固定结构 JSON 蓝图模板。

#### 实时 3D 预览与调整
- **开启阵列 3D 实时预览**：在世界中以 3D 包围盒形式实时预览排列效果。
- **采样步距 (格)**：沿 Bezier 曲线采样的间隔距离（单位：方块）。越小生成越平滑密实。
- **3D 阵列姿态旋转微调**：提供 `滚转角 Roll`、`俯仰角 Pitch`、`偏航角 Yaw` 滑块及 `0° 重置` 按钮，用于调整截面铺设倾角。
- **🧊 下发道路建造任务**：打包当前生成的道路方块，发送至服务端由殖民地建筑法师 NPC 自动建造！

---

### 4.3 选项卡三：💾 模板与工具 (Templates & Tools)

#### 模板文件管理
- **输入模板名称**：在文本框中输入名称（例如 `main_road`）。
- **保存 JSON 模板**：将当前样条线所有点导出为 JSON 保存至 `config/wandscape/splines/`。
- **读取 JSON 模板**：以当前玩家位置为放置原点载入样条线。

#### 视图与快捷工具
- **切换 2D 俯瞰视角 (G)**：切换垂直俯视视角。
- **打开操作指南 (H)**：快捷弹出本说明文档。
- **清空画布**：移除所有控制节点，重置画布。
- **关闭 Studio**：退出道路制作工坊。

## 🛠️ 6. 常见问题

### Q: 曲线弯角处方块有断裂或空隙？
控制柄拉得过长导致曲率过大。缩短控制柄距离（2~4 格），或减小采样步距（改为 1.0）提高采样密度。

### Q: 拖拽轴时另一侧控制柄也跟着动？
这是“对称切线手柄锁定”功能。按住 Shift 拖拽可临时解除，或在面板中取消勾选 `对称切线手柄锁定`。

### Q: 模板文件存在哪里？
`<游戏目录>/config/wandscape/splines/*.json`
