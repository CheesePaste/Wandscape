# ➰ 样条线可视化编辑器（Spline Editor）详细指南

样条线编辑器是 Wandscape 最强大的道路建造工具。通过 ImGui 可视化面板，你可以在 3D 世界中实时添加、编辑、拖拽贝塞尔曲线控制点，打造优雅弯道、环形路与复杂立体道路。

---

## 🚪 1. 如何进入与退出编辑器

### 进入方式
1. 按 **`V`** 打开 Wandscape 控制面板。
2. 点击左侧 **Road / 道路** 图标，进入道路工具。
3. 点击左侧工具栏 **`Spline`** 按钮。
4. V 面板自动关闭，ImGui 样条线编辑器随即在屏幕右侧弹出。

### 退出方式
- 按 **`ESC`** 退出编辑器（不按住右键时）。
- 或点击 ImGui 面板底部 **`Close Editor`** 按钮。

---

## 🎮 2. 视角控制（Camera Flight / 灵魂出窍模式）

进入编辑器后，玩家角色处于灵魂出窍（Freecam）状态，WASD 输入将被拦截（不会移动游戏内的玩家实体）。你可以通过以下方式自由飞行观察：

| 操作 | 功能 |
| :--- | :--- |
| **右键按住 + 移动鼠标** | 旋转视角（Yaw / Pitch） |
| **右键按住 + WASD** | 灵魂出窍 3D 飞行移动（沿视角方向飞行，游戏角色不动） |
| **右键按住 + Space** | 垂直向上飞行 |
| **右键按住 + Shift** | 垂直向下飞行 |
| **右键按住 + Ctrl** | 飞行加速（2 倍速） |
| **直接滑动鼠标滚轮** | 调节灵魂出窍飞行速度（0.02 ~ 5.0，无需按 Ctrl，Actionbar 实时显示提示） |
| **G 键** | 切换鸟瞰/俯视视图（Top-Down View） |

松开右键后，鼠标光标自动释放，可以操作 ImGui 面板或在世界中点选控制点。

## 🖱️ 3. 世界内交互（点选、添加、拖拽）

### 3.1 添加控制点（ADD 模式）
1. 在 ImGui 面板中选择 **`Add Point (Left-Click Surface)`**。
2. 松开右键（光标释放状态），将鼠标对准世界中的方块表面。
3. **左键单击** → 在该方块顶面创建一个新的样条线锚点（Anchor）。
4. 重复添加 2 个以上锚点，编辑器自动生成贝塞尔曲线预览。

### 3.2 选择控制点
- 在 ADD 或 EDIT 模式下，**左键单击** 已有的锚点球体即可选中。
- 选中后，该点周围显示 **RGB 三维轴 Gizmo**（红 = X、绿 = Y、蓝 = Z）。
- 在 EDIT 模式下，还可以点选控制柄（Prev / Next 小球体）。

### 3.3 三维轴拖拽（Axis Gizmo Drag）
选中控制点后：
1. 将鼠标悬停在某个轴箭头上（会高亮）。
2. **左键按住拖拽** → 沿该轴方向平移选中的锚点或控制柄。
3. 支持 6 个方向：X+、X-、Y+、Y-、Z+、Z-。
4. 拖拽时按住 **`Shift`** → 临时解除对称锁定（仅移动当前控制柄，不联动对侧）。

### 3.4 删除控制点
- 选中控制点后按 **`Delete`** 或 **`Backspace`** 删除。
- 或在 ImGui 面板中点击 **`Delete Selected Point`** 按钮。

## 🖥️ 4. ImGui 面板控件详解

### 4.1 EDITOR MODE（编辑模式）

| 控件 | 功能 |
| :--- | :--- |
| **Add Point** | 切换到添加模式。左键点击世界方块表面即可新建锚点。 |
| **Select & Edit** | 切换到编辑模式。左键点选锚点/控制柄，拖拽 Gizmo 轴移动。 |

### 4.2 CURVE CONFIGURATION（曲线配置）

| 控件 | 类型 | 默认值 | 功能 |
| :--- | :--- | :--- | :--- |
| **Closed Loop** | Checkbox | 关闭 | 勾选后样条线首尾相连，形成封闭环路。 |
| **Global Translation X/Y/Z** | 3 个数值输入框 | 0.0 | 输入偏移量后点击 `Shift All`，整条曲线所有控制点同时平移。 |
| **Shift All** | Button | — | 应用全局平移。执行后自动清零偏移输入框。 |

### 4.3 POINT LIST（控制点列表）

- 滚动列表显示所有锚点的序号与世界坐标 `(X, Y, Z)`。
- 点击列表项可快速选中对应锚点，自动切换到 EDIT 模式。
- 列表高度固定 150px，超出可滚动。

### 4.4 SELECTED POINT（选中点详情）

选中锚点后显示此区块：

| 控件 | 功能 |
| :--- | :--- |
| **Active Handle: Anchor / Prev / Next** | 切换当前操作目标：锚点本身、前控制柄、后控制柄。 |
| **Coordinates X / Y / Z** | 精确坐标输入框，可直接输入数值微调位置（步进 0.05 / 0.5）。 |
| **Symmetric Locked** | 勾选后，移动一侧控制柄时另一侧自动镜像联动，保持曲线平滑。 |
| **Align Symmetric** | 仅在取消锁定时显示。点击后重新开启对称锁定。 |
| **Delete Selected Point** | 红色按钮。删除当前选中的锚点。 |

### 4.5 ARRAY GENERATION（阵列生成）

这是最终生成道路方块的核心配置：

| 控件 | 类型 | 默认值 | 功能 |
| :--- | :--- | :--- | :--- |
| **Blueprint** | 下拉选择 | `test_road_5x1` | 选择道路截面蓝图模板（决定道路宽度、材质、层高）。 |
| **Enable Array Preview** | Checkbox | 关闭 | 开启后，沿曲线实时预览道路方块的阵列效果。 |
| **Step Distance** | 数值输入 | `2.0` | 沿曲线每隔多少格放置一个截面蓝图实例。值越小越密集，曲线越平滑。推荐 1.0~3.0。 |
| **Roll / Pitch / Yaw** | 滑块 | `0°` | 截面蓝图沿曲线切线方向的旋转偏移角度（-180° ~ 180°）。用于倾斜路面或调整铺设朝向。 |
| **Build Array Task** | Button（绿色） | — | 将阵列数据序列化发送到服务端，NPC 法师将在世界中实际铺设道路方块。 |

### 4.6 TEMPLATES（模板存取）

| 控件 | 功能 |
| :--- | :--- |
| **Template Name** | 文本输入框。输入模板文件名（不含 `.json` 后缀）。 |
| **Save To JSON** | 将当前样条线所有控制点导出为 JSON 文件，保存至 `config/wandscape/splines/` 目录。第一个锚点作为原点，其余坐标存储相对偏移。 |
| **Load JSON** | 从文件加载样条线模板，以当前玩家位置作为放置原点。 |

### 4.7 ACTIONS（操作）

| 控件 | 功能 |
| :--- | :--- |
| **Clear Canvas** | 清空所有控制点，重置画布。 |
| **Close Editor** | 关闭编辑器并隐藏 ImGui。 |

## 🛠️ 6. 常见问题

### Q: 曲线弯角处方块有断裂或空隙？
控制柄拉得过长导致曲率过大。缩短控制柄距离（2~4 格），或减小 Step Distance（改为 1.0）提高采样密度。

### Q: 拖拽轴时另一侧控制柄也跟着动？
这是 Symmetric Locked 功能。按住 Shift 拖拽可临时解除，或在面板中取消勾选 `Symmetric Locked`。

### Q: 模板文件存在哪里？
`<游戏目录>/config/wandscape/splines/*.json`
