## 📖 UI 控件与字段 API 级别明细字典 (UI Options API Reference)

| 控件标识 / 标签 | 类型 / 范围 | 默认值 | 详细作用机制与计算影响 |
| :--- | :--- | :--- | :--- |
| **`Anomaly Entry`** | List Row | — | 发生故障的建筑列表行。展示建筑名称、坐标与故障类型。 |
| **`Anomaly Status`** | Enum (`String`) | `SHUTDOWN` | `SHUTDOWN` (缺乏维护费停运) / `BROKEN` (物理损毁需修复)。 |
| **`Repair / Restart Button`** | MedievalButton | — | 自动调度法师 NPC 前往修缮或从仓库补充维护元素重启建筑。 |
