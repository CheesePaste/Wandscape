# 🚁 俯瞰选建与旋转编辑器（Overview Mode）傻瓜式指南

Overview 模式为玩家提供 RTS 视角的鸟瞰施工体验。

![Overview 视角示意图](wandscape:textures/gui/guide/overview_diagram.png =200x100)

---

## 1. 🚀 快捷键与控制指南

### 开启 Overview
- 按下键盘 **`V` 键** 打开 Wandscape 控制面板，默认进入 Overview 俯瞰飞行模式。
- 按下 **`C` 键** 可在飞行视野与鼠标自由光标间切换。

### 选建与旋转蓝图
- 从底部轮播选单挑选建筑蓝图（如市政厅、仓库、商店）。
- 移动鼠标预览白色 3D 旋转线框。
- 使用 **旋转按钮或快捷键** 旋转建筑朝向（4 方向自动对齐楼梯与门）。
- 点击确认放置，法师 NPC 将会自动前来按照逐层顺序进行建造！

---

## 🛠️ 常见问题排查（Troubleshooting & FAQ）

### Q1: 旋转建筑后放下去楼梯朝向反了？
- **解决**：最新版已经修复了 4 方向 `BlockState` 方向对齐与旋转 BoundaryBox 预计算，请升级至 1.3.1a+。
