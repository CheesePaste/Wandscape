## 🎮 1. 如何打开与切换道路编辑模式

### 步骤一：开启道路施工模式
1. 在游戏内按下键盘 **`V` 键** 打开 Wandscape 控制面板。
2. 点击左侧工具栏的 **【Road / 道路】图标**（或直接按下 **`R` 键**），即可开启道路施工投影模式。

### 步骤二：如何在 3 种模式与材质之间切换
- 按下 **`C` 键** 可以在【光标选择 UI 面板】与【准心视线交互】之间快速切换。
- **模式切换**：光标状态下，在底部/侧边栏工具选项中点击切换 **`REPLACE` (替换)**、**`FILL` (填充)** 或 **`SPLINE` (样条线)**。
- **材质预设切换**：双击底部卡片挑选石砖、石板、泥土路或铺面。

## ⌨️ 3. 通用快捷键与鼠标按键对照表

| 操作 / 按键 | 触发功能 |
| :--- | :--- |
| **鼠标右键** | 设定起点 / 添加样条线控制节点（或右键全清重选） |
| **鼠标左键** | 设定终点 / 选择并拖拽曲线控制句柄 |
| **Enter (回车键)** | 确认提交下发建造任务（发送数据包） |
| **Backspace (退格键)** | 撤销上一次设定的端点 |
| **ESC 键** | 退出道路编辑模式（无损返回） |
