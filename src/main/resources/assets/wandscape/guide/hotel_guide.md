# 🏨 旅馆（Hotel）API 级详细指南

旅馆为游览殖民地的游客提供夜间过夜住宿！

---

## 📖 UI 控件与字段 API 级别明细字典 (UI Options API Reference)

| 控件标识 / 标签 | 类型 / 范围 | 默认值 | 详细作用机制与计算影响 |
| :--- | :--- | :--- | :--- |
| **`Max Occupancy`** (`maxOccupancy`) | Display Int | `10` | 旅馆总客房容量。决定了夜间能够同时收留住宿的游客上限。 |
| **`Current Occupancy`** | Display Int | `0` | 当前已入住过夜的游客总人数。 |
| **`Guest List`** (`guestNames`) | ScrollableList | 空 | 展示当前正在房间内休息过夜的游客名字清单。 |
