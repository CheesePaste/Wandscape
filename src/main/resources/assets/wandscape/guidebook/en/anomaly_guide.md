# Building Maintenance

Buildings **never stop working from damage or manual shutdown** — when a building is hit by monsters or explosions it only loses some blocks visually, while still operating and contributing normally. Missing blocks are filled back in via **Repair** in the overview camera.

## Repairing Buildings

- Open the overview camera with V, aim at the damaged building, and click **Repair** below the info box.
- Clicking Repair makes wizards fill in the missing blocks per the blueprint (the warehouse must have the matching elements / materials).
- **Damage doesn't auto-repair**: you must click "Repair" to trigger it.
- A damaged building keeps working normally even if you never repair it — only the appearance is affected.

## Construction Progress

After you submit a construction site, wizards lay the building down block by block; when materials run short it pauses at "Waiting for Materials" and resumes automatically once the warehouse has them. To see which stage a building is at, aim at it in the overview camera; to open the construction UI of an empty site (not a single block placed yet), right-click it from overview.
