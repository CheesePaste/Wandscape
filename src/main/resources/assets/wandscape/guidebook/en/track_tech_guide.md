# 3. Tech Track

The tech track focuses on automation, production lines, and warehouse distribution.

## Core Pillars

- **Mana Grid**: Transfer energy automatically using [Mana Nodes](guidebook:node_guide) and the [Altar](guidebook:altar_guide).
- **Workshops**: Delegate mass production to mages via [Workstations](guidebook:workstation_guide).
- **Logistics**: The [Warehouse Network](guidebook:warehouse_guide) automates transport and supply.
