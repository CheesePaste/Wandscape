# 市政厅

殖民地的核心设施，统一管理小镇名称、殖民地等级、经验与声望，也是吸引法师 NPC 加入的关键。必须先建市政厅、创建殖民地，其余建筑才能运转。

## 建造与启用

按 **V** 打开面板 → 建造面板【市政厅】分类 → 放置。**首次建造免费**。

放置后**右键**市政厅，第一次交互会让你给小镇**命名并创建殖民地**。

## 面板信息

| 项目 | 说明 |
|---|---|
| 小镇名称 | 随时修改 |
| 等级 | 殖民地等级；越高则人口上限越高、解锁的建筑越多 |
| 经验条 | 小镇经营进度，满后自动升级 |
| 声望 | 由游客满意离场积累；声望越高，每天进城门的游客越稀有、越有钱 |
| 蓝图选建 | 直接打开建筑选建面板，挑选建筑发布建设计划 |

## 无仓库时充当仓库

殖民地还没有仓库建筑时，市政厅面板会多出一个 **「仓库存取」** 按钮——点击打开仓库存取界面，可手动存入/取出物资与元素，给后续建造补料。建好仓库后按钮消失，存取改由仓库建筑承担。

## 生成游客开关

市政厅面板底部有 **「生成游客」** 切换按钮，**默认开启**，**按钮描金边时即为开启状态**。关闭后本殖民地不再生成新游客（已到来的游客不受影响，仍会正常游览、购物、离场）；需要时再点一下重新开启。

> 该开关只控制本殖民地。另有一个全局开关 `tourist.spawnEnabled`（默认 `true`）在配置文件里——关掉它时 **所有殖民地一律不生成游客**，无论各自市政厅的「生成游客」是否开启。

## 全灭保底复活

阵亡的法师只能去[祭坛](altar_guide.md)复活，而祭坛需要一名**在世法师**走到祭坛旁施放。**全员阵亡时祭坛也跟着停摆**——这时面板底部的 **「复活法师」** 按钮会亮起金边，点一下即可把本殖民地**最近阵亡的那名法师**在**市政厅门口**拉回来（同样是 1 血 0 蓝的虚弱状态）。

| 项目 | 说明 |
|---|---|
| 可用条件 | 本殖民地**一名法师都不剩**，且存在死亡记录 |
| 次数 | 点一次只救回**一名**——救回后按钮立即置灰 |
| 冷却 | **5 分钟**（按殖民地各自计算）；冷却中按钮显示倒计时 |
| 代价 | 免费，不消耗任何物资 |

救回来的人就是你的**唯一自举起点**：其余阵亡者仍需由这名法师回祭坛逐个接回。所以小镇务必有一座能用的祭坛。

## 升级

游客**三条需求条全满**、夜晚满意离场时，小镇获得经验。游客等级相对小镇越高，给予的经验越多。经验充满后自动升级，解锁高级建筑蓝图并提高人口上限。

> 高级建筑需要殖民地等级达标才能建造；等级不足时，建造栏中对应蓝图显示为锁定。
