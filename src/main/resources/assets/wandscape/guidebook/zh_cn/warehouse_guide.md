# 仓库

存放小镇全部元素与物资。建造、合成从这里扣料，游客消费收入也回到这里。**材料存进仓库，NPC 才能取用。**

## 两个页签

**总览（Overview）**

| 项目 | 说明 |
|---|---|
| 元素面板 | 小镇储备的 **7 种元素**（土 / 木 / 水 / 火 / 金 / 风 / 暗）存量 |
| 物品列表 | 可搜索的物资清单，按名字模糊搜 |
| 物资缺口 | 合成台或工作站卡住时，缺的材料在此高亮 |

**存取（Exchange）**

大箱子式格子界面：每个格子一种物品，右下角显示数量。

| 操作 | 效果 |
|---|---|
| 左键点击仓库物品 | 取出一整叠到光标 |
| 右键点击仓库物品 | 取出一半到光标 |
| Shift + 左键点击仓库物品 | 快速取出到背包 |
| 光标有物品时点击仓库格子 | 存入仓库 |
| 右键（光标有物品） | 存入 1 个 |
| Shift + 左键点击背包物品 | 快速存入仓库 |
| 光标持有物品时点右下角 **×** 销毁格 | 销毁光标上的物品（左键整叠、右键单个） |

右下角的 **×** 是销毁格（类似创造模式的删除 X）：把想丢掉的物品拿到光标上——从自己背包拿起、或刚从仓库取出都行——再点 × 即可销毁。存进仓库请用上面的存入操作，别误点 ×。物品拿在光标上就能销毁，仓库里放着的格子本身不受影响。

背包区域与原版容器完全一致：数字键 1-9 换栏、Q 丢弃、拖拽均分等快捷键都可用，也兼容一键整理类模组。

## 仓库容量

仓库容量按**仓库建筑数**累加：**每座仓库提供 50000** 容量（还没有独立仓库时按 1 座计），建得越多装得越多。**每件物品计 1**，不可堆叠的法杖、卷轴也一样占 1；元素另有独立的元素栏，**不计入**容量。

| 状态 | 表现 |
|---|---|
| 容量未满 | 存取、合成照常 |
| 仓库已满 | 玩家无法再存入；合成站 / 制作站 / 魔法工坊里「消耗材料制作物品」的任务会标记 **「仓库容量不足」** 并原地等待，容量空出后自动继续，无需重发 |
| 豁免 | 商店补货（含为补货而自动合成）、物品分解、拆迁回收与任务退还不受满仓影响，保证殖民地不停摆 |

已满时的空间读数：总览页元素下方、以及交换页「仓库」标题右侧都会显示当前 **占用/上限**，满仓时变红。想腾空间可到交换页取走或用[工作站](workstation_guide.md)**分解** 成元素。

## 无仓库建筑时

殖民地还没有仓库建筑时，[市政厅](townhall_guide.md)面板会显示「仓库存取」按钮，可临时充当仓库存取物资；NPC 取料也会改从市政厅位置发射物品。建好仓库后恢复正常。

## 启动资金

放下第一座建筑时，仓库自动收到**每种元素各 6000** 的启动元素。

## 元素消耗

建造、合成都要消耗元素。元素短缺时靠[元素节点](node_guide.md)采集、或[工作站](workstation_guide.md)分解补充。

## 提示

> NPC 取料时会显示物品**飞行动画**，从仓库送到法师手里，属正常表现。
