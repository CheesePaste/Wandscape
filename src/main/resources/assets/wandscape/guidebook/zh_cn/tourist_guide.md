# 游客

游客清晨沿路进镇，三条需求条填满后离场。经营循环围绕游客的三条需求条展开。

## 三条需求条

游客有三条**需求条**：**舒适 / 魔法 / 奇观**。他们会去能填满这些条的地方——商店购物、服务建筑接受服务、放松建筑恢复精力，逐条填满。

每个游客有一个**画像**：偏爱舒适、偏爱魔法或偏爱奇观，会优先去填满自己偏好的那条。

## 信息屏（准心对准游客，右键打开）

| 项目 | 说明 |
| :--- | :--- |
| **需求条** | 舒适 / 魔法 / 奇观三条，当前值与需求值 |
| **精力** | 交互消耗精力；耗尽后只能去放松建筑 |
| **等级** | 富裕等级（1~5）。越高越能花钱，需求也越高 |
| **钱包** | 手持旅费 |
| **停留** | 已住几晚 / 计划总天数 |
| **行程** | 去过哪些建筑及每次收益（舒适+X 魔法+Y 奇观+Z · 精力+W） |

## 游客的一天

1. **进镇**：清晨沿路进镇，**只走铺好的路**。
2. **逛街**：自动选择最合适的目的地（按需求缺口 + 精力 + 钱包计算，最缺的优先）。商店购物、服务建筑接受服务、放松建筑泡澡、取款机取钱。
3. **过夜**：入夜（约 19:40）优先去**旅馆**；入住后记住这家旅馆，每晚回来睡，清晨精力回满继续逛街。还没找到旅馆的游客，傍晚（约 21:00）会直接去最近的旅馆。
4. **离场**：**三条需求条全满**的游客当晚开心离场，小镇获得**经验**；住进旅馆的游客住到停留结束（2~4 天）才离场；既没住店又没满条的游客在深夜（21:00 后）离场。

游客逗留 **2~4 天**，整个停留期间每栋建筑只逛一次（**取款机例外**：旅费没取完且钱包又见底时，隔一段时间还能再去取，钱是分批取出来的）。

## 三类配套建筑

| 类型 | 功能 |
|---|---|
| **放松建筑**（澡堂等） | 回复精力；精力耗尽又不愿离场的游客前往 |
| **取现建筑**（自动取款机） | 补充钱包；旅费花光但未逛够的游客前往 |
| **旅馆** | 过夜恢复精力，见[旅馆指南](hotel_guide.md) |

三类建筑配齐，游客才能在镇内填满需求条后离场。

## 排队与容量

| 项目 | 说明 |
|---|---|
| 接待量 | 由建筑的**交互位**数量决定 |
| 排队 | 交互位全满时，后来的游客排队；等太久会离场 |
| 扩容 | 增加交互位，或多建同类型建筑 |

## 法师游客

约 **5% 的游客是法师游客**。三条需求条全满的法师游客会在[酒馆](tavern_guide.md)留下简历，可**免费**招募。

## 经营要点

- **路修好、建筑建齐**：商店、服务、放松、取现各类建筑齐全，游客才有去处。
- **三值对路**：建筑带的舒适 / 魔法 / 奇观值决定能填哪条需求条、填多快。
- **交互位与道路充足**：游客逛得顺畅，三条需求条全满离场的比例更高。
