# 施法策略

法师战斗时放什么魔法，由两件事决定：**策略栏里装了什么魔法卷轴**，以及你选的**总体预设**。

打开方式：**准心对准法师，右键 → 信息屏 → 「策略」按钮**；法师小屋「晋升与指令」卡里的策略按钮也能打开同一个策略屏。

## 法师的魔法从卷轴来

法师的战斗魔法全靠策略栏 12 格里装着的卷轴——没有「天生会一整套法术」。想让法师放什么，就把什么卷轴装进策略栏：

- 本模组的**魔法卷轴**在[魔法工坊](magic_station_guide.md)用元素合成，每张绑定一个具体魔法（如光束、陨石）。
- 殖民地成立时自带的 3 名法师默认装好光束 + 陨石；**酒馆招募的法师没有起始战斗魔法**——想让它参战，先做卷轴给它装上。
- 装了铁魔法或诡厄巫法模组时，它们的卷轴 / 聚晶也能入栏，见下节。

## 两处设置：装卷轴 + 选预设

**卷轴槽（中部）**：12 格按四类排成四行——**单体攻击 / 群体攻击 / 防御 / 增益**，每行 3 格。把背包里的卷轴拖进格子即装备（取出即拿回卷轴，**Shift** 可快速转移）：

- 卷轴放在哪一行，就按哪一类参与施放顺序；同类去重，每行最多 3 个。
- 同一行里格子的先后（上 → 下）= 该类内的施放优先级，越靠前越先放。

**总体预设（顶部 4 个按钮）**：决定四类魔法整体谁先谁后：

| 预设 | 施放顺序（高 → 低） |
| :--- | :--- |
| **均衡** | 群体攻击 → 单体攻击 → 增益 → 防御 |
| **火力** | 单体攻击 → 群体攻击 → 防御 → 增益 |
| **支援** | 增益（治疗优先）→ 防御 → 群体攻击 → 单体攻击 |
| **防御** | 防御 → 增益 → 群体攻击 → 单体攻击 |

右侧「**特殊**」是只读面板：传送、治疗等**天生固有**的魔法列在这里，所有法师默认使用、不可更换，只在特定情形自动触发（危险时自救回血、寻路失败传送）。

## 机制细节

- 自动施法时，按「预设定的类别顺序 → 行内格子顺序」从高到低扫，挑**第一个能放**的：目标有效、冷却已过、魔力够。
- **改动即保存**，不用点确认；每格配置只作用于当前这个法师。
- 祭坛魔法（如复活）不入自动施法、也不占策略栏——见[祭坛](altar_guide.md)。
- 没装进策略栏的魔法，法师不会施放。

## 第三方魔法需要对应装备

**铁魔法卷轴**（铁魔法模组）只能装备给「Curios 饰品栏佩戴了**法术书**」的法师。可入栏的卷轴数量 = **法术书的容量**（书能记多少法术，品级越高容量越大）。未佩戴法术书时卷轴无法放入，已装上的**停用但不删除**，佩戴后自动恢复。

**诡厄巫法聚晶**（诡厄模组）需要法师**主手（法杖栏）持有诡厄法杖**，且全策略栏**只能装 1 个**聚晶。未持杖时无法放入、已装的停用，持杖后恢复。

法术书走[NPC 面板](npc_guide.md)的「饰品栏」入口、诡厄法杖走法杖槽给法师装备。本模组原生卷轴不受上述门控。

> 装过第三方魔法时，策略屏底部会显示状态行（如「铁魔法 2/5」「聚晶 1/1」）；装备缺失时变警示行（「无法术书：铁魔法停用」「无法杖：聚晶停用」）。拿着被门控的卷轴悬停到格子，会红字提示拦截原因。
