# 自定义

> 文件都放数据包里，`/reload` 之后生效；从游戏内的建筑扫描器起手最省事。

模组有三条改内容的门路：**扫描器**在游戏里把房子框出来导出，不碰文件；**数据包**用 JSON 改建筑、元素定价、配方、魔法与箱子；**API** 给写 Java 的模组作者，数据包做不到的事才用它。

## 放哪里

放进存档的 `<存档>/datapacks/<包名>/data/<命名空间>/<类别>/`。命名空间随便取；要覆盖模组自带的那份，才必须用 `wandscape` 命名空间加同一个文件名。

（下一页）

建筑放 `buildings/<包名>/`，元素定价放 `element_mappings/`，配方与卷轴放 `craft_recipes/`，魔法与法阵放 `magic_spells/` 和 `magic_circles/`，野外箱子放 `exploration_regions/`，平衡数值放 `wandscape_balance.json`。扫描器导出的就是这里。

## 随世界还是全局

数据包**跟世界走**：每个存档各带一份，扫描器导出的建筑只活在当前存档里。模组自带的内容在 jar 里，不随存档变。

设置中心的配置是**全局**的，存在 `config/wandscape-*.toml`：服务端的全服共用，客户端那几项只管自己这台机器。扫描器预设和建筑预览也在客户端的 `config/wandscape/` 下。
