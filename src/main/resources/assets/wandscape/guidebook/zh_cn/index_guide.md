# 概览

Wandscape（魔法小镇）是一个大型模组，以魔法与城镇建设为主题

玩法主线

《0，入门》

《0.5，推荐了解的功能》

《1，游客线》推荐休闲玩家观看

功能与类别

《元素与三值》经济系统介绍

《管理面板》交互，管理与建造城镇

《法师》工人与战斗单位介绍

《游客》短居小镇的消费者

《施法》法师放什么魔法由什么决定

《建筑》能盖什么，以及每一类建筑怎么用

《管理》管理面板，以及建造、道路、任务、设置四个子模式

《魔法》法师、施法，与每个魔法能干什么

《装备与物品》法师的装备和玩家自己的小道具

《自定义》导入自己的建筑和建筑包，改元素价值

《联动与兼容》和其它模组一起玩
