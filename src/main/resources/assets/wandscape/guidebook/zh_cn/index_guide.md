# Wandscape 指南

欢迎来到 Wandscape！把它变成一座魔法小镇从这里开始。

Wandscape 是个模拟经营模组：你放下建筑，**法师 NPC 替你干活**（建造、采集、合成、守卫），**游客沿路入城消费**。你要做的，是决定小镇往哪走。这本书按 **H** 键随时打开。

> 第一次玩？先读[新手入门：从空城到游客小镇](getting_started_guide.md)，它讲解完整游戏循环。
