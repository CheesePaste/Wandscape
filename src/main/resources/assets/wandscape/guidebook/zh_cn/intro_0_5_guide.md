# 0.5，推荐了解的功能

新手教程只覆盖了市政厅，仓库，工作站三个建筑，但是还有一些有用的没涉及到，这里补充。

《工作站》《合成站》《魔法工坊》这类建筑，每一座同一时间只做一件活，想让它们快些就在别处多盖几座：每座各排各的队，可以同时开工。只是干活的是法师，镇上法师都忙着的时候，多盖也不会有更多产出。

## 除了教程，这几样也值得先看

- 《元素与城镇等级》了解经济系统
- 《法师》城镇的工人兼战斗人员
- 《祭坛》祭坛可以复活法师，在前期很有用
- 《合成站》有提升战力的法杖与探索，打BOSS都很有用的道具
- 《酒馆》可以招募法师
- 《法师小屋》可以训练法师，战力的核心
- 《道路子模式》平地和铺路功能
