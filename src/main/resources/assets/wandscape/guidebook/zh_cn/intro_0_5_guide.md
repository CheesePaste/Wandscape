# 0.5，推荐了解的功能

新手教程只覆盖了市政厅、仓库、合成站三个基础建筑，但还有许多极为关键的核心功能未在初期强制引导中展开，本篇作重点补充。

## 核心系统速览

- [元素与三值](guidebook:economy_guide)：了解小镇的基础经济与魔力系统。
- [法师](guidebook:mages_guide)：城镇的核心劳动力兼战斗守卫。
- [祭坛](guidebook:altar_guide)：祭坛可以复活法师，在前期探索与保全战力时至关重要。
- [合成站](guidebook:crafting_guide)：制作提升战力的法杖、探险道具与战斗耗材。
- [酒馆](guidebook:tavern_guide)：招募更多各具专长的法师居民。
- [法师小屋](guidebook:mage_hut_guide)：训练法师属性与技能，小镇战斗力的核心。
- [道路系统](guidebook:road_guide)：平整地形与快速铺设道路，吸引游客的生命线。
