# 魔法工坊

魔法工坊用元素把**魔法卷轴**造出来——法师只会施放[施法策略](strategy_guide.md)栏里装着的魔法，造出卷轴给它装上，它才有对应的战斗能力。

## 操作

1. 在建造面板放一座**魔法工坊**，法师会按队列执行合成任务。
2. **准心对准工坊，右键**打开面板：左侧列出可合成的魔法条目（可按名搜索），右侧显示任务队列。
3. 选一个魔法 → 设数量 → **Submit**。做好的魔法卷轴进殖民地**仓库**。
4. 从仓库取出卷轴放到自己背包，再到法师的[策略栏](strategy_guide.md)拖进对应分类槽装备。

## 可合成的魔法卷轴

| 魔法卷轴 | 解锁等级 | 元素消耗 |
| :--- | :--- | :--- |
| **光束** | 1 级 | 火 ×650 + 土 ×550 |
| **治疗** | 1 级 | 水 ×650 + 木 ×550 |
| **陨石** | 1 级 | 火 ×700 + 金 ×500 |
| **石化** | 1 级 | 土 ×700 + 金 ×500 |
| **虚弱力场** | 10 级 | 暗 ×8000 + 风 ×7000 |
| **防御强化** | 10 级 | 金 ×8000 + 土 ×7000 |
| **魅惑** | 20 级 | 暗 ×24000 + 火 ×23000 |
| **背水一战** | 20 级 | 暗 ×24000 + 火 ×13000 + 水 ×10000 |

## 提示

- 卷轴进的是殖民地仓库，[法杖](crafting_guide.md)也是——装备给谁、按什么顺序放，由你在[法师 NPC 面板](npc_guide.md)和[施法策略](strategy_guide.md)里决定。
- 传送、复活等魔法没有卷轴配方：复活走[祭坛](altar_guide.md)。
