一、设计目标

· 将过剩资源转化为发展动力：商店售卖物品产生元素利润，服务建筑从游客交互中获得元素收入。
· 装饰建筑获得策略价值：通过范围辐射加成，将布局变为有深度的经营决策。
· 奇观提供全局级影响：不仅是数值加成，更是改变殖民地规则的核心建筑。
· 游客行为自然有节奏：精力值、兴趣判断、昼夜循环共同驱动访客流动。
· 法师招募有保底机制：满意法师的信息留存酒馆，玩家不会错过。

二、游客实体

2.1 基本属性

属性 说明
等级  随着殖民地三数值上升而提升，等级越高游客精力值越高，满意值提升阈值越高，其中法师游客满意度100%后招募时的数值越高。
精力值 每次交互消耗，耗尽后离开
满意度 0-100%，由交互结果累积
偏好 对建筑类型（buildingTypeId）的偏好权重，默认 40（5..100）。每次访问该类型建筑后衰减-15，驱动下次选站和满意度计算
样貌 普通市民（95%）或法师（5%）


2.2 游客离开条件（三区段规则）

游客在以下条件触发时离开殖民地：

**满意度 ≥ 100**：法师简历即时存入酒馆。游客不主动离开，不住宿。精力耗尽 / 夜幕且空闲 / 空闲超时后离开。
**满意度 70–99**：精力耗尽或夜幕降临时 → 寻找宾馆。有空位则入住（次日精力回满、满意度保持），无空位则离开。
**满意度 < 70**：精力耗尽时离开；夜幕且空闲时离开；空闲超时（可配置）后离开。

2.3 满意度达到100%时的特殊处理

· 满意度首次达到 100% 时，法师样貌游客的招募信息即时存入酒馆招募列表（最近 5 位）。
· 游客不因满意度满而主动离开，100% 满意度游客不会入住宾馆。
· 招募信息永久保留在酒馆，玩家可随时招募。

2.4 宾馆入住

· 触发条件：满意度在70%-99%，且触发了上述离开条件。
· 行为：不离开，转而寻找殖民地宾馆。
· 宾馆有空位 → 入住，第二天精力值回满，满意度保持。
· 宾馆无空位 → 离开。
· 宾馆本身是服务建筑，入住行为产生满意度和元素收入。

三、商店建筑

3.1 货品与进货

· 货物种类由建筑 JSON 固定定义（数据驱动，不同商店类型差异化）。玩家可通过 GUI 调整每种货物的 `max_stock`。
· 每日清晨统一进货，货品从殖民地中央仓库直接扣除元素（不是物品），无需 NPC 搬运。
· 当日未售出的货品在次日进货前清除，产生自然损耗。

3.2 利润模型

· 商店货品在制作时消耗了元素（设为X）。
· 游客购物时消耗一份货品，殖民地获得 1.2X 的元素收入。
· 即商店是元素净产出建筑，利润率固定为20%。

3.3 货品与三数值的关系

· 每种货物可配置 comfort/magic/wonder 值（默认 0）。
· 商店三值 = 建筑基础值 + 所有有货货物的三值合计。
· 缺货（仓库元素不足以进货）→ 该货物三值加成归零。

四、服务建筑

4.1 功能

· 游客使用服务建筑时，消耗精力值，产生满意度和元素收入。
· 服务建筑包括：宾馆、图书馆、体育馆等供游客使用的建筑。

4.2 宾馆

· 服务建筑的一种。
· 游客入住时，产生满意度和元素收入。

五、装饰建筑

5.1 不与游客交互

· 装饰建筑是静态摆设，游客不会主动与之交互。

5.2 范围辐射加成

· 装饰建筑拥有自身的三数值。
· 这些值不直接计入殖民地总数值，而是以范围辐射方式，全额加成给曼哈顿距离内的所有功能性建筑（商店、服务建筑等）。
· 不同装饰建筑可配置不同辐射半径。
· 一个功能建筑可接收多个装饰建筑的加成，加成叠加。
· 加成上限：单个功能建筑从装饰建筑获得的总加成，不超过其自身基础三数值的100%（可配置）。

六、奇观建筑

6.1 不与游客交互

· 奇观是特殊建筑，不参与游客的交互系统。

6.2 效果

1. 大量三数值加成：直接计入殖民地总数值，不受装饰建筑加成上限限制。
2. 全局被动效果：对殖民地整体产生持续性规则级影响。

示例：

奇观 三数值加成 全局效果
浮空水晶 魔法+15, 奇观+20 所有NPC法术强度+1
法师塔 魔法+20, 奇观+25 所有建筑魔法值+2
星象台 舒适+10, 奇观+30 所有商店售价提升10%
折跃门枢纽 奇观+40 殖民地间物资传送解锁

七、建筑维护费
· 所有建筑都有消耗N种元素的维护费。
· 建筑维护费不足或者主动关闭或者建筑受损 → 进入shutdown状态。
· Shutdown效果：
· 建筑提供的三数值归零。
· 商店完全关闭，无法与访客交互。
· 服务建筑仍可被使用，但游客交互时产出的元素量减半。
· 装饰建筑对周围建筑的三数值提升归零。
· 奇观全局加成暂时不影响，防止出bug。
· 工作站，节点等特殊建筑，遵循其自身规则。（目前为工作时间延长100%，产出降低50%）
· 不产生维护费，不会死档。

八、酒馆招募法师

· 酒馆招募列表保存最近5位满意度达到100%的法师访客信息。
· 信息永久有效，不自动过期，直到玩家招募或手动清除。
