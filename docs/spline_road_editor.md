# 样条线道路编辑器设计规范 (Spline Road Editor Design Specification)

本文档定义了样条线道路编辑器（模型编辑器）的交互设计、渲染机制、坐标系统与保存格式。

## 1. 背景与目标
为了支持更复杂的曲线道路铺设，模组引入了一个独立的**样条线模型编辑器 (Spline Model Editor)**。
- 本编辑器是一个**纯粹的模型/路径编辑器**，不干涉原有的玩家自主铺路与 NPC 寻路系统。
- 编辑好的样条线未来可以作为“蓝图的平铺目标”。

## 2. 交互状态机与操作模式

编辑器主要基于 `GLFW` 鼠标事件捕获，并与 ImGui 面板相结合：

### 2.1 视角旋转与飞行
- **按住右键**：调用 `grabMouse()`，隐藏鼠标光标并启用视角旋转，允许玩家使用 `W/A/S/D/Space/Shift` 自由飞行。
- **松开右键**：调用 `releaseMouse()`，显示鼠标光标，允许操作 ImGui 界面和在世界中指向交互。

### 2.2 编辑操作模式
通过 ImGui 面板或快捷键切换两种主要状态：
1. **添加点模式 (Add Mode)**
   - 鼠标悬停在世界中的方块表面时，显示一个“幽灵样条点” (Ghost Point)。
   - **鼠标左键点击**：在视线交点处追加一个样条线锚点，并自动在其切线两侧生成对称的控制点。
2. **选择与编辑模式 (Select & Edit Mode)**
   - 鼠标悬停在已有的锚点或控制点上时，该点会变为高亮黄色。
   - **鼠标左键点击**：选中该点，并在其上渲染三维轴移动手柄 (3D Axis Gizmo)。
   - **按住左键拖动 Gizmo 轴**：沿指定轴线（X/Y/Z）平移该点的三维世界坐标。

### 2.3 控制点对称关联
- 默认状态下，同一个锚点的两个控制点（前控制点 $C_{prev}$ 与后控制点 $C_{next}$）保持**镜像对称**（与锚点共线、距离相等），保证曲线在锚点处是 $G^1$ / $C^1$ 连续的。
- 玩家可以**按住 Shift 键拖拽**或在 UI 面板中解锁，来断开镜像关联，从而制作尖锐的折角。

### 2.4 样条线的闭合与增删
- **首尾闭合 (Loop)**：在 ImGui 面板上可以开启 "闭合环路"。开启后，最后一个点与第一个点之间自动连接。
- **删除点 (Delete)**：选中任意锚点后，按 `Delete` / `Backspace` 键或面板上的 "删除" 按钮即可将其移除。
- **中间插入点 (Insert)**：按住 `Ctrl` 键，将鼠标悬停在已有的曲线段上并点击左键，即可在对应的曲线上中途插入一个新的锚点。

### 2.5 俯视模式 (Top-Down View)
与 V 面板的 Overview 模式一致，方便从高空整体观察/规划道路：

- **进入**：按 `G` 键或点击 ImGui 面板 "Top-Down View" 按钮。相机瞬间移动到当前编辑位置上方 20 格并垂直向下看（`pitch = 90°`）。
- **操作**：
  - **按住右键拖拽**：旋转俯视相机（可水平转 yaw、在 ±90° 内调整俯仰角）。
  - **W / A / S / D**：在水平面平移（W 沿相机朝向）。
  - **Space / Shift**：垂直升降。
  - **滚轮**：沿视线方向移动 —— 正俯视时即垂直缩放高度。
  - **Ctrl + 滚轮**：调节俯视平移速度（1–100 格/秒）。
- **退出**：再次按 `G` 或点击面板按钮，相机恢复到进入前的位置与朝向；按 `ESC` 退出编辑器时自动清理。
- 俯视模式下依然可以左键点选/添加样条点、拖拽 Gizmo 轴（射线从俯视相机发出）。

**实现**：`MixinSplineEditorCamera` TAIL 注入 `Camera.setup` 覆盖相机位置/旋转（与 `MixinOverviewCamera` 相同机制），相机控制逻辑在 `SplineEditorController.handleTopDownCamera`，状态在 `SplineEditorClientState`（`enterTopDown`/`exitTopDown`）。

## 3. 坐标系统与保存设计

### 3.1 绝对坐标编辑，相对坐标保存
- **世界编辑**：在 3D 场景中，样条点与控制点直接使用**绝对世界坐标 (BlockPos / Vec3)** 进行存储、移动和渲染。
- **整体平移**：在 ImGui 面板上，提供一个 XYZ 全局平移增量面板。用户点击平移时，对样条线内所有的点坐标进行全局累加偏移。
- **局部化保存 (Serialization)**：
  - 保存为 JSON 文件时，编辑器会自动将**第一个锚点**的绝对坐标作为原点 $(0, 0, 0)$。
  - 其余所有锚点和控制点的坐标，在序列化时全部转换为**相对第一个锚点的相对 3D 浮点偏移量 (Vec3)**。
  - 这种设计确保导出的样条线模型不含固定的绝对坐标，方便未来作为蓝图模版应用在世界的任何位置。

### 3.2 高度模型 (Elevation Mode)
- **贴地生成 (Terrain Snap - 默认)**：样条线生成的初始点默认贴在世界地表（非空气方块的最高高度）。
- **自由 3D (3D Free)**：曲线在 $Y$ 轴上完全采用三维贝塞尔插值。用户可以通过 3D Gizmo 拖动锚点 and 控制点的 $Y$ 坐标来实现高架、空中桥梁的搭建。

## 4. 3D 渲染与视觉反馈

为了保证编辑时的可读性，在客户端使用以下渲染效果：
1. **样条线曲线段**：OpenGL 细分渲染的粗发光线条（金黄色/嫩绿色）。
2. **锚点**：大蓝色半透明立方体/球体。
3. **控制点**：小青色/粉色球体，与对应的锚点之间通过白色细虚线相连。
4. **选中状态**：选中点上渲染 X(红)、Y(绿)、Z(蓝) 的 3D Axis 箭头，允许一维拖动。
