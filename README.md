> **你是镇长，法师干活。**

## 简介

Wandscape 是一个**魔法 × 小镇建设 × 模拟经营**模组：放下一个方块，一座小镇就此诞生——法师 NPC 替你采集元素、砌砖盖房、炼制药剂、守卫城墙，你只管经营。然后游客沿着你的道路慕名而来：逛街、泡酒馆、住进旅馆，还会告诉全世界你的小镇到底好不好。

## 上手十分钟

1. **放下市政厅**——每种建筑的第一座都免费，建镇不花一分钱。给小镇起个名字，就此开张。
2. **建一座仓库和几个元素节点**——仓库一开始就预存每种元素 2000，节点法师随后自行开工采集。
3. **看法师干活**——每座建筑都自带施工图纸，NPC 一块块码砖、运料、修补，全程不用你插手。

没有繁琐的新手教程，没有任务清单。按 **H** 打开游戏内指南，然后……放手玩。

## 🏰 搬砖的是法师

- 建筑近 20 种、分 9 大类：市政厅、仓库、7 种元素节点、4 家商店、酒馆、旅馆、工作站、合成站、酿造站……
- 蓝图施工：法师按图自动建造、补料、修复损坏。
- 舒适 / 魔力 / 奇观三值喂给游客满意度，满意度再化为殖民地经验；等级越高，解锁的建筑与配方越多。
- 维护费每日结算——元素不足时建筑会**分级停摆而不是崩坏**，补足后自动重启，绝不卡档。
- 系统还会**提前**预判元素缺口、自动加派采集任务，让你很少措手不及。

## ⚗️ 七种元素，一套经济

- 地、木、水、火、铁、风、暗——节点采集、工作台分解、合成货物、再花出去，环环相扣。
- 游戏里几乎所有物品和方块都有对应的元素价值——铁锭 = 64 铁，末影珍珠 = 64 暗。整张价目表都由原版配方自动推导。
- 合成站与酿造站把元素变成法杖和药水，配方随殖民地等级逐步解锁。

## 👥 游客有自己的生活

- 游客沿你的道路入城，各有精力、满意度、偏好和心情。
- 他们逛商店、泡酒馆、入夜住进旅馆——头顶气泡会说话，到达、购物、离城都有故事般的播报。
- 商店自动从仓库补货、按各建筑利润率回笼元素；装饰建筑向周边辐射加成。
- 把法师游客的满意度喂到 100%，他们会在酒馆留下简历——去招募，壮大你的法师团队。
- 就算你远在天边，游客也照样过他们的小日子——区块一卸载，影子模拟立刻悄无声息地接管。

## ✨ 会施法的法师

- 你的法师是货真价实的巫师——在发光的魔法阵中施法（环、弧、多边形、星形、符文），抬手就是一道纯光光束。
- 每一次施法都是一场小演出：纯粒子动画，不开光影也好看，开了光影更好看。
- 法杖是**你**自己的施法工具——右键施放魔法阵，永不损坏。在合成站锻造并给法师装备上：基础、进阶、大师三档，逐级提升法术强度。
- 每个法师都有自己的属性——法术强度、施法速度、工作速度、护甲等等。

## ⚔️ 保卫小镇

- 法师自动守卫建筑周边：主动索敌、光束反击，被打还会记仇。
- 袭击以市政厅为中心展开（复用原版袭击机制），击退波次后小镇声名远扬。

## 🛠️ 管理操作

- **V 键俯瞰面板**：飞上小镇上空，远程放置建筑、查看统计，不用亲自跑路。
- **道路系统**：建筑够多时路网自动生成——也可以用路刷手绘，或用样条编辑器画曲线路；游客与法师都沿路行走。
- **建筑扫描方块**：框选任意现成结构，一键导出成可复用蓝图。生存模式也有可合成的扫描器，亲手盖的杰作也能扫描到任何地方重建。
- **15 个原版成就**：建到 50 栋楼、升到 30 级、住满旅馆、盖出 50×50 的巨型建筑、击退袭击……还有一座 NPC 击杀末影人的成就。
- **每日统计 + 30 天走势摘要**，小镇经营状况一目了然。

## FAQ

**要不要事无巨细地管理？** 不用。采集、建造、合成，法师自己认领工作。你决定盖什么、盖在哪，剩下的他们来。

**元素不够怎么办？** 建筑会停摆等待而不是崩坏。补足元素后自动重启——模组设计上就保证你永远不会把自己卡死。

**会改原版玩法吗？** 几乎不改。不新增矿石、不重做机制——模组是数据驱动的，只加了几个物品（法杖、扫描器），大部分参数都能用 TOML 配置，适合放进整合包。

**经营小镇很累吗？** 我们刻意反着设计：远程管理、没有繁琐的日常维护、一切可恢复。你是镇长，不是跑腿的。

## 项目结构

```
src/main/java/com/wsteam/wandscape/   # 模块源码（core/engine/shared/building/wand/npc/tourist/magic/...）
src/main/resources/data/wandscape/    # JSON 配置（建筑/配方/元素映射/蓝图/魔法阵/叙事）
docs/                                 # 模块文档与数据格式（以真实代码为准，权威）
architecture/                         # 旧结构快照（部分过时，以 docs/ 为准）
spec/                                 # JSON 格式规范
magicarchitecture/                    # 魔法阵设计契约（spec/原则/示例）
```

## 设计原则

1. **高兼容性** — 不修改原版行为，JSON 数据驱动，方块映射用标签，`/reload` 热重载
2. **原子化设计** — 模块间通过 `WandscapeApis` + EventBus 通信，不跨包直接引用
3. **稳定优先** — 所有失败路径有兜底，不崩溃、不卡死，维护费不足自动分级停摆保护
4. **引擎是请求层，适配层是实现** — `core/` 零 MC 依赖，MC 实现集中在 `engine/`
5. **不折磨玩家** — 远程管理面板，NPC 自动干活，一切可恢复
6. **性能优化** — 物流用单实体视觉合并 + 金边气泡计数，避免大量实体掉落掉帧
