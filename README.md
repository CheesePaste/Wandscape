# Wandscape

<p align="center"><img src="minecraft_title.png" alt="Wandscape — 魔法小镇" width="70%"></p>

**中文** | [English](README.en.md)

Minecraft NeoForge 1.21.1 模组 — **《魔法小镇》**（Wandscape）：魔法城镇自动化建设与模拟经营。

玩家使用魔法法杖指挥 NPC 法师建造建筑、采集元素、合成物品、执行仪式；小镇走上正轨后，游客沿道路入城，商店、宾馆、装饰与奇观构成完整的经营循环。

## 核心玩法

### 城镇自动化

- **法杖系统**：单一法杖物品 + NBT 定义行为标签与等级，永不损坏，动态染色，JSON 配方驱动
- **NPC 法师**：携带法杖执行任务，拥有个人魔力池，死后可复活，ECS 组件桥接
- **任务系统**：8 种原子操作 + 蓝图 DSL，全局任务池按距离/效率/属性评分派单，资源不足自动触发采集或合成
- **城镇建设**：JSON 数据驱动的建筑（节点/仓库/工作站/合成站/药水站/商店/服务/酒馆/市政厅），V 面板一键建造，蓝图投影预览，市政厅与仓库首次免费
- **元素经济**：7 种元素（地/木/水 → 火/铁/风 → 暗）稀有度逐级递增，通过方块映射、采集、分解、合成在仓库中流转
- **三数值驱动**：舒适值/魔法值/奇观值决定城镇等级，解锁建筑与配方
- **道路系统**：MST 路网自动生成 + 编辑器 + 宽面渲染 + 样条线物流 + 路径规划，游客与 NPC 均沿路移动
- **物流优化**：NPC ↔ 仓库 ↔ 商店运输采用单实体视觉合并，大批同种物品仅生成一个携带数量的实体，避免掉帧

### 魔法阵（Magic Circle）

- **数据驱动**：魔法阵由 `MagicCircleSpec` JSON 定义——环/弧/多边形/星形/符文 5 类元素 + 动画曲线，Web 编辑器导出后 MC 端与编辑器渲染同一份几何数据
- **粒子渲染**：可染色点粒子逐帧撒出，非 shader 方案，任何光影包下正常显示
- **施放**：法杖右键或调试命令触发，法阵垂直于法杖朝向，动画结束后可染色信标光束射向准星目标
- **示例**：内置 `arcane_hexagram` 大型六芒星召唤阵 spec
- **定位**：战斗（守卫）系统的视觉层，法杖、命令与仪式共同复用；光束伤害在守卫系统后续阶段实现

### 模拟经营（游客经济）

- **游客实体**：等级/精力/满意度/偏好/样貌，每日沿道路入城，按满意度区段交互、入住宾馆或离开
- **商店**：每日清晨从仓库进货，游客购物按固定利润率（默认 20%）回笼元素
- **服务建筑与宾馆**：游客使用消耗精力、产生满意度与元素收入；高满意度游客夜间入住宾馆，次日精力回满
- **装饰建筑**：范围辐射加成周边功能建筑的三值，上限为建筑自身的 100%
- **奇观建筑**：直接计入城镇三值 + 全局 modifier（法术强度/售价/规则解锁）
- **维护费与停摆**：建筑按周期结算维护费，元素不足分级 shutdown，杜绝死档
- **酒馆招募**：满意度 100% 的法师游客简历存入酒馆，可随时招募

### 管理操作

- **V 面板**：俯瞰视角默认进入，左侧侧边栏（建造/道路/统计/警告），顶部全宽 HUD 展示三值/天数/游客/NPC/元素储量
- **建筑扫描方块**：框选任意建筑直接生成 JSON 配置
- **统计系统**：日快照 + 30 天滚动摘要

## 项目结构

```
src/main/java/com/wsteam/wandscape/   # 模块（core/engine/shared/building/wand/npc/tourist/magic/...）
src/main/resources/data/wandscape/    # JSON 配置（建筑/配方/元素映射/蓝图/道路/魔法阵）
architecture/                         # 代码结构唯一真相来源，开始工作前先读
docs/                                 # 设计文档与路线图
spec/                                 # JSON 格式规范
magicarchitecture/                    # 魔法阵设计契约（spec/原则/示例）
```

## 设计原则

1. **高兼容性** — 不修改原版，JSON 数据驱动，方块映射用标签，`/reload` 热重载
2. **原子化设计** — 模块间通过 `WandscapeApis` + EventBus 通信，不跨包直接引用
3. **稳定优先** — 所有失败路径有兜底，不崩溃、不卡死，维护费不足自动分级关停保护
4. **引擎是请求层，适配层是实现** — `core/` 零 MC 依赖，MC 实现集中在 `engine/`
5. **不折磨玩家** — 远程管理面板，NPC 短距离步行/长距离传送，复活后仍可工作
6. **性能优化** — 物流单实体视觉合并 + 金边暗灰底气泡悬浮数，避免大量实体掉落掉帧
