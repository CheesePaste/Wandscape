## 简介

Wandscape 是一个**魔法 × 小镇建设 × 模拟经营**模组（Minecraft 1.21.1 / NeoForge）：放下一个方块，一座小镇就此诞生——法师 NPC 替你采集元素、砌砖盖房、炼制药剂、守卫城墙，你只管经营。然后游客沿着你的道路慕名而来：逛街、泡酒馆、住进旅馆，还会告诉全世界你的小镇到底好不好。

## 上手十分钟

1. **放下市政厅**——每种建筑的第一座都免费，建镇不花一分钱。给小镇起个名字，就此开张。
2. **建一座仓库和几个元素节点**——仓库一开始就预存每种元素 6000，节点法师随后自行开工采集。
3. **看法师干活**——每座建筑都自带施工图纸，NPC 一块块码砖、运料、修补，全程不用你插手。

用泥土、原木、圆石和小麦种子合成一本**指南书**，随时右键翻开——20+ 篇图文教程，中英双语。没有繁琐的新手教程，没有任务清单，放手玩。

## 🏰 搬砖的是法师

- **建筑 50+ 座、分 13 类**：市政厅、仓库、7 种元素节点、祭坛、酒馆、旅馆与豪华酒店、18 家商店、工作站、合成站、酿造站、装饰建筑。
- 蓝图施工：法师按图自动建造、补料、修复损坏。
- 建造中的建筑可**一键撤销**、全额退还材料；**工地面板**清楚列出还缺哪些材料、何时完工。
- 完好运营的建筑是**安全区**——围墙之内不自然刷怪。
- 舒适 / 魔力 / 奇观三值喂给殖民地等级，等级解锁更多建筑与配方。
- 系统还会**提前**预判元素缺口、自动加派采集任务，让你很少措手不及。

## ⚗️ 七种元素，一套经济

- 地、木、水、火、铁、风、暗——节点采集、工作台分解、合成货物、再花出去，环环相扣。七种可合成的**元素物品**会自动存入仓库。
- 游戏里几乎所有物品和方块都有对应的元素价值——铁锭 = 64 铁，末影珍珠 = 64 暗。没错，整张价目表都由原版配方自动推导。
- 对整合包友好：任何映射都可以用简单配置禁用或覆盖。
- 合成站与酿造站把元素变成法杖和药水，配方随殖民地等级逐步解锁。

## 👥 游客有自己的生活

- 游客沿你的道路入城，各有**舒适 / 魔力 / 奇观三条需求**、偏重某一维的画像、自己的钱包、精力与心情。
- 他们逛商店、泡酒馆、入夜住进旅馆——头顶气泡会说话，到达、购物、离城都有故事般的播报。
- 面向游客的建筑分四类——**商店 / 服务 / 休闲 / ATM**，每座都有标记好的交互点。游客在交互点前礼貌排队（按点独立队列、严格先来后到），入住旅馆还会真睡在床上。
- 商店自动从仓库补货、按利润率回笼元素；装饰建筑向周边辐射加成。
- 把法师游客的满意度喂到 100%，他们会在酒馆留下简历——去招募，壮大你的法师团队。
- 就算你远在天边，游客也照样过他们的小日子——区块一卸载，影子模拟立刻悄无声息地接管。

## ✨ 会施法的法师

- 你的法师是货真价实的巫师——在发光的魔法阵中施法（环、弧、多边形、星形、符文），抬手就是一道纯光光束。魔法全部数据驱动：治疗、陨石、石化、衰弱领域……各有独立冷却、耗蓝与法阵表现。
- 每一次施法都是一场小演出：纯粒子动画，不开光影也好看，开了光影更好看。
- 在合成站锻造法杖、给法师装备上——基础、进阶、大师三档，逐级提升法术强度。法杖永不损坏。
- 每个法师都有自己的属性——法术强度、施法速度、工作速度、护甲等等。
- 阵亡的法师能在**祭坛**复活——万一整个殖民地团灭，最后一道保底魔法会在市政厅门口把大家救回来。

## ⚔️ 保卫小镇

- 法师自动守卫建筑：主动索敌、走位躲开投掷物、光束与魔法反击，被打还会记仇。
- 每个法师可在面板上切换**守卫 / 跟随 / 和平**三种模式。
- 袭击以市政厅为中心展开（没错，借用了原版的村庄袭击机制）。击退波次，烟花为你的小镇庆祝。

## 🛠️ 管理操作

- **V 键俯瞰面板**：鸟瞰视角飞过小镇，远程放置建筑、查看统计，一步都不用走。按 **F4** 可一键隐藏所有界面，看个清爽。
- **道路系统**：建筑够多时路网自动生成——也可以用路刷手绘，或用样条编辑器画出蜿蜒的曲线。
- **建筑扫描方块**：框选任何现成结构，一键导出为可复用蓝图——支持多门与装饰实体；生存模式也能合成，你亲手盖的得意之作照样能扫出来重建。
- **30 个原版成就**：建到 50 栋楼、升到 30 级、旅馆满员、拥有一座超过 50×50 的建筑、击退袭击。
- **每日经营统计** + 30 天走势摘要，小镇的兴衰一目了然。

## FAQ

**要不要事无巨细地管理？** 不用。采集、建造、合成，法师自己认领工作。你决定盖什么、盖在哪，剩下的他们来。

**元素不够怎么办？** 建造与合成会等待补料而不是失败，补足后自动继续——模组设计上就保证你永远不会把自己卡死。

**会改原版玩法吗？** 几乎不会。没有新矿石，不改平衡——模组数据驱动，只添加几件物品（法杖、两个扫描方块、一本指南书、七种元素物品），多数系统还能用 TOML 配置，跟整合包很合得来。

**经营小镇很累吗？** 我们刻意反着设计：远程管理、没有繁琐的日常事务、一切可恢复。你是镇长，不是跑腿的。

**能参与开发吗？** 完全开源，MIT 协议——建筑、代码、文档、建议都欢迎。

## 设计原则

1. **高兼容性** — 不修改原版行为，纯新增内容与机制；JSON 数据驱动，方块映射用标签，`/reload` 热重载
2. **按功能聚合，直接协作** — 一个功能域一个包；跨域直接调用业务类，不建搭桥层、不滥用事件解耦
3. **稳定优先** — 所有失败路径有兜底，不崩溃、不卡死；关键设施（市政厅/仓库/工作站）拆到只剩最后一座时受保护
4. **纯逻辑与 MC 解耦** — 核心算法、蓝图解析、任务评分不依赖 Minecraft 类，保持可移植
5. **不折磨玩家** — 远程管理面板，NPC 自动干活，一切可恢复
6. **性能优化** — 物流用单实体视觉合并 + 气泡计数，避免大量实体掉落掉帧
